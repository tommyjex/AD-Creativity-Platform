# 字幕翻译与压制仓库扩展

用户已要求把视频字幕翻译和压制加入已创建的私有仓库。

## 边界与兼容

- 保留仓库和 Python 包名称，版本升至 0.2.0。
- 迁入 Ark 翻译适配器、原字幕排版编译器、MediaKit 多轨提交/查询/轮询客户端。
- 提供独立翻译、排版、压制提交、任务查询 SDK；HTTP 提供翻译、压制提交与查询。压制异步返回供应商任务 ID 和最终视频 URL，调用方保存任务及下载结果。
- 原平台保留工作区、RBAC、数据库、资产签名和输出入库；原 import 路径保留为适配层并注入平台配置和日志。
- 完整保持逐视觉行、纵向固定、横向扩框、字体测量、默认颜色/底板、音轨与旋转契约。本次不调整可读性参数。
- 配置和日志无平台依赖；供应商凭据仅来自运行时环境，翻译原文只进入注入的 TLS 回调。

## 执行

1. 复制可独立运行的核心，补齐独立配置、SDK 和 API。
2. 将平台对应实现切换为兼容层。
3. 迁入离线翻译、排版、MediaKit 测试与 OFL 字体 fixture，添加独立接口与运行流程测试。
4. 构建并验证 0.2.0 wheel，更新平台 vendor 依赖和源码归档。
5. 执行独立测试、平台字幕/多轨回归、Ruff、编译及 diff 检查，更新发布说明。

真实模型翻译质量和 MediaKit 成片渲染质量需要真实调用才能验证；离线测试不代表该项验收。
