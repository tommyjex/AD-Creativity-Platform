# 分镜视频编辑弹窗设计

## 背景

当前分镜视频工作台采用左侧镜头列表、列表下方编辑器、右侧视频预览的布局。用户点击镜头后，仍需向下滚动才能编辑视频生成提示词和管理参考素材，镜头数量较多时操作路径尤其冗长。

本次改造将提示词与参考素材管理迁移到镜头编辑弹窗。点击任意镜头即可就地编辑，无需滚动到列表底部；右侧视频状态、预览与生成能力保持不变。

## 目标

- 点击分镜卡片后直接打开对应镜头的编辑弹窗。
- 参考素材位于提示词上方，用户编辑提示词时能看到素材及其引用编号。
- 已关联素材支持缩略预览，并能通过点击卡片向提示词插入标准引用。
- 保留现有素材上传、资产库关联、移除和提示词保存能力。
- 保留现有右侧视频预览、生成、重试和删除能力。

## 非目标

- 不修改后端接口、数据库结构或分镜视频生成流程。
- 不增加参考素材拖拽排序。
- 不增加富文本提示词编辑器。
- 不改变视频生成提示词的后端字段格式。
- 不重构分镜视频工作台之外的页面。

## 交互设计

### 打开与选择镜头

点击任意分镜卡片时：

1. 将该镜头设置为当前选中镜头，右侧视频预览同步切换。
2. 打开该镜头的编辑弹窗。
3. 请求该镜头最新的视频配置。
4. 配置加载完成后展示参考素材和提示词；加载期间展示明确的加载状态，不允许编辑旧配置。

### 弹窗布局

弹窗采用单列纵向布局，桌面端最大宽度约为 `960px`，窄屏退化为接近全屏的单列滚动布局。

内容顺序：

1. 顶部：镜头编号、标题、时长和关闭按钮。
2. 参考素材区：参考图、参考视频、参考音频分组展示。
3. 视频生成提示词区：大尺寸多行文本框及使用说明。
4. 固定底部操作栏：取消和保存提示词。

提示词保存成功后弹窗保持打开，方便继续上传、预览或调整素材。

### 参考素材卡片

已关联素材按各类型配置数组中的顺序编号：

- 图片：`参考图1`、`参考图2`
- 视频：`参考视频1`、`参考视频2`
- 音频：`参考音频1`、`参考音频2`

每张素材卡片包含：

- 缩略预览区域。
- 标准引用名。
- 文件描述或名称。
- 独立预览按钮。
- 移除按钮。

缩略预览规则：

- 图片使用安全访问 URL 显示缩略图。
- 视频使用安全访问 URL 显示静音视频缩略预览，完整播放在预览层进行。
- 音频显示音频类型封面，并在预览层提供播放器。
- 素材无安全 URL 或加载失败时显示类型占位，不渲染不可信地址；引用和移除操作仍可使用。

### 插入素材引用

- 点击素材卡片主体时，在提示词文本框当前光标位置插入对应标准引用名。
- 提示词文本框未聚焦或没有有效光标位置时，将引用追加到文本末尾。
- 插入时根据相邻字符补充必要空格，避免引用词与原文本粘连。
- 点击预览按钮或移除按钮不会插入引用。
- 预览按钮打开二级预览层；关闭预览后焦点返回原按钮。

### 删除后的编号同步

移除素材可能导致同类型后续素材编号前移。系统只处理完全匹配的标准引用词：

- 删除 `参考图1` 时，移除提示词中的 `参考图1` 引用。
- 原 `参考图2`、`参考图3` 依次改为 `参考图1`、`参考图2`。
- 图片、视频、音频分别处理，互不影响。
- 使用临时占位符完成批量替换，避免连续替换产生碰撞。
- 自动同步后的提示词标记为未保存，并在弹窗内提示用户检查和保存。

系统不改写非标准文本，例如“第一张参考图”或文件名。

### 未保存关闭确认

弹窗维护“当前草稿”和“最后保存值”。两者不一致时视为存在未保存修改。

以下关闭入口行为一致：

- 顶部关闭按钮。
- 点击遮罩。
- 按下 `Escape`。
- 点击底部取消按钮。

存在未保存修改时显示二次确认，提供：

- 继续编辑。
- 放弃修改并关闭。

没有未保存修改时直接关闭。放弃修改后，下次打开从服务端配置重新加载。

## 技术设计

### UI 基础能力

新增 `@radix-ui/react-dialog` 依赖，并在 `frontend/components/ui/dialog.tsx` 封装项目级 Dialog 组件。使用 Radix 处理：

- Portal 与遮罩层。
- 焦点锁定和焦点恢复。
- `Escape` 关闭。
- 弹窗标题、描述和无障碍语义。
- 遮罩点击关闭事件。

未保存确认使用同一 Dialog 基础能力实现嵌套确认层，不使用浏览器原生 `window.confirm`。

### 工作台组件

主要改动位于：

- `frontend/components/workspace/storyboard-video-workspace.tsx`

新增或调整的局部组件：

- `StoryboardShotEditorDialog`：负责弹窗结构、关闭拦截和加载状态。
- `ReferenceManager`：改为缩略卡片布局，并接收插入引用与打开预览回调。
- `ReferenceAssetCard`：负责单个素材的缩略图、引用名、预览和移除入口。
- `ReferenceAssetPreviewDialog`：负责图片、视频和音频的大尺寸预览。
- `PromptEditor`：暴露 textarea ref 或插入回调，以支持光标位置插入。

镜头列表下方不再渲染内嵌 `PromptEditor` 和 `ReferenceManager`。

### 状态

工作台新增以下状态：

- 编辑弹窗是否打开。
- 弹窗配置是否正在加载。
- 当前草稿提示词。
- 最后保存的提示词。
- 当前预览素材。
- 是否显示未保存关闭确认。

保留现有状态：

- `selectedShotId`
- `configs`
- `pendingAction`
- `feedback`
- `shotTasks`

素材保存操作继续使用现有 `pendingAction` 防止重复提交。保存提示词、上传、关联和移除分别显示局部 loading。

### 数据流

#### 打开弹窗

1. 用户点击镜头卡片。
2. 更新 `selectedShotId` 并打开弹窗。
3. 调用 `getStoryboardShotVideoConfig`。
4. 将返回配置写入 `configs`。
5. 使用 `video_prompt ?? effective_video_prompt` 初始化当前草稿和最后保存值。

沿用现有请求序号机制，忽略快速切换镜头产生的过期响应。

#### 保存提示词

1. 提交去除首尾空白后的草稿；空字符串提交为 `null`。
2. 调用 `updateStoryboardShotVideoConfig`。
3. 更新 `configs`、本地镜头和父级项目。
4. 将服务端返回值设置为当前草稿和最后保存值。
5. 显示成功反馈，弹窗保持打开。

#### 上传素材

1. 沿用现有文件类型和大小校验。
2. 调用 `uploadStoryboardShotReference`。
3. 更新当前镜头配置。
4. 调用现有项目刷新逻辑获取完整资产及安全访问 URL。
5. 重新渲染素材缩略卡片。

刷新失败时保留已成功关联的配置，使用类型占位展示素材，并提示缩略图暂不可用。

#### 关联与移除素材

- 关联继续使用 `attachStoryboardShotReference`，成功后更新配置。
- 移除继续使用 `removeStoryboardShotReference`，成功后更新配置并同步标准引用编号。
- 素材操作即时持久化；提示词因编号同步产生的修改需要用户显式保存。

## 错误处理

- 配置加载失败：弹窗展示错误和重试入口，不显示可能过期的可编辑表单。
- 提示词保存失败：保留草稿，显示错误，弹窗保持打开。
- 素材上传失败：保留其他表单状态，清理对应 loading。
- 素材关联或移除失败：不修改本地配置和编号，显示错误。
- 项目刷新失败：保留接口已返回的配置，素材使用占位预览。
- 媒体预览失败：展示“暂无法预览”，不影响引用和移除。
- 视频生成相关错误仍显示在右侧预览区域，不迁入编辑弹窗。

## 无障碍与键盘操作

- 弹窗使用 `role="dialog"`、可读标题和描述。
- 打开后焦点进入弹窗，关闭后回到触发镜头卡片。
- `Tab` 焦点不会离开弹窗。
- `Escape` 遵循未保存关闭确认。
- 素材卡片插入、预览和移除均为独立可聚焦操作。
- 每个操作提供包含素材引用名和文件描述的可访问名称。
- 图片缩略图使用描述性 `alt`；装饰性类型封面隐藏于辅助技术。

## 测试方案

在 `frontend/tests/project-workspace.test.tsx` 扩展分镜视频工作台测试，覆盖：

1. 点击不同镜头时打开对应标题的编辑弹窗。
2. 弹窗加载对应镜头最新配置。
3. 参考素材区域在 DOM 顺序上位于提示词编辑器之前。
4. 图片与视频使用安全 URL 渲染缩略预览。
5. 无安全 URL 时显示类型占位。
6. 点击素材卡片在 textarea 光标位置插入正确引用。
7. 点击预览和移除按钮不会插入引用。
8. 图片、视频和音频预览层使用正确媒体元素。
9. 删除素材后标准引用正确移除和重新编号。
10. 保存提示词调用现有 API，成功后弹窗保持打开。
11. 未保存时通过关闭按钮、遮罩或 `Escape` 触发确认。
12. 放弃修改后重新打开恢复服务端值。
13. 上传、资产库关联、移除和视频生成现有行为不回归。
14. 快速切换镜头时过期配置响应不会覆盖当前弹窗。


## 验收标准

- 用户点击分镜卡片后，无需滚动即可编辑该镜头的参考素材和提示词。
- 参考素材始终展示在提示词上方。
- 已关联图片和视频有可识别的缩略预览，音频有可识别封面和播放预览。
- 素材卡片显示正确编号，点击主体可向光标处插入标准引用。
- 删除素材后标准引用编号与当前素材顺序一致。
- 提示词保存成功后弹窗保持打开。
- 未保存提示词不会在无确认的情况下丢失。
- 后端 API 和数据结构保持兼容。
- 现有分镜视频预览、生成、重试和删除流程正常。
