# 图片节点预览布局优化设计

## 背景

图片节点已经取消常驻标题，但精准编辑按钮仍占用卡片内部空间，图片预览底色也与文本节点不一致。此次调整让图片节点聚焦于媒体预览，同时保留完整的精准编辑与状态表达能力。

## 已确认方案

采用方案 A：精准编辑按钮固定在图片节点卡片右上角外侧。

- 按钮位于卡片边界之外，避免压缩或遮挡图片预览。
- 按钮避开位于节点左右中部的输入、输出端口及连线热区。
- 按钮保持现有图标、辅助标签、Tooltip、禁用态和事件隔离。
- 按钮始终与所属图片节点形成明确的视觉关联。

未采用的方案：

- 右侧中部外置：容易与图片输出端口及连线交互冲突。
- 右下角外置：节点靠近其他内容或画布底部时更容易产生视觉拥挤。

## 卡片内部布局

图片节点常态下，卡片内部只呈现图片预览区域：

- 不渲染标题行或内部操作区。
- 预览容器使用与文本节点一致的 `bg-card` 灰色底色。
- 图片继续使用绝对定位与 `object-contain`，完整保留原始宽高比，不裁切、不拉伸。
- 无可用图片时，等待或不可用状态仍在同一灰色预览区域内居中显示。
- 分辨率和“已框选”角标继续保留，因为它们属于图片状态信息而非操作栏。

显式重命名时，图片节点仍可临时显示原位名称输入框；提交或取消后恢复纯图片预览布局。

## 组件边界

改动集中在 `AigcFlowNodeComponent` 和 `NodeImageMedia`：

- 图片节点的 `AigcPreciseEditDialog` 触发按钮从 `NodeActions` 中移出，作为卡片外的绝对定位操作呈现。
- 其他节点的下载操作和标题栏操作继续复用 `NodeActions`，不改变既有行为。
- 精准编辑 Dialog、BBox 数据、图片来源解析、节点名称语义和后端契约保持不变。
- 节点尺寸、端口位置、连线、运行投影和自动保存逻辑保持不变。

## 交互与可访问性

- 外置按钮继续提供 `aria-label="精准编辑：<图片名>"` 和现有 `title`。
- 无图片或只读管理状态下沿用现有禁用规则。
- 按钮点击和指针按下事件不得触发节点拖拽、选中切换或画布交互。
- 外置按钮层级高于卡片，但不得覆盖 NodeResizer 控点或端口。
- 打开、确认、取消精准编辑的行为不变。

## 验收

组件测试覆盖：

- 图片节点常态无标题行、无内部操作区。
- 精准编辑按钮位于卡片外置操作容器中。
- 图片预览使用 `bg-card` 灰色底色并保持 `object-contain`。
- 分辨率和“已框选”角标继续呈现。
- 按钮可用、禁用、Dialog 打开和事件隔离行为无回归。
- 文本、视频、音频、模型和控制节点布局不受影响。

Playwright 在桌面、平板和手机视口验证：

- 外置按钮稳定停靠在图片节点右上角，不与端口、连线、预览、相邻节点或缩放控点重叠。
- 图片预览完整显示，灰色底色与文本节点一致。
- 重命名和精准编辑流程可用。
- 页面无新增控制台错误或布局溢出。
