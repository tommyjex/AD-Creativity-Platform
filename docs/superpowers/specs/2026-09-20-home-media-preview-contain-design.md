# 首页媒体预览完整显示设计

## 背景

首页媒体画廊的放大预览在部分视口中会裁切竖图底部。虽然图片元素已经使用 `object-contain`，但预览主体的尺寸分配不稳定，导致媒体区域可能溢出 Dialog 的可视空间。

## 目标

- 图片、视频在首页放大预览中始终按原始宽高比完整显示。
- 预览区域保留黑色留边，不拉伸、不裁切、不要求媒体铺满容器。
- 桌面和窄屏都不出现底部画面被 Dialog 页脚遮挡的情况。

## 非目标

- 不改变首页瀑布流缩略图布局。
- 不改动媒体资产数据、下载地址或视频播放控件。
- 不为预览增加缩放、全屏或裁剪工具。

## 方案

预览 Dialog 保持固定的视口约束高度，并采用三行 Grid：

1. 标题栏使用内容高度。
2. 媒体区使用 `minmax(0, 1fr)` 并设置 `min-h-0`，获得稳定且可收缩的可用空间。
3. 页脚使用内容高度。

媒体区使用黑色背景。图片和视频均在该区域中居中：

- 图片使用 `max-h-full max-w-full object-contain`。
- 视频使用 `h-full w-full object-contain` 和原生控制条。
- 不使用 `object-cover`、固定媒体宽高或变形缩放。

## 验收

- 竖图在桌面 Dialog 中显示顶部与底部完整画面。
- 横图、方图同样保持原始比例且不溢出。
- 窄屏视口中标题、媒体区、页脚不重叠，Dialog 无横向溢出。
- 图片预览继续包含可访问替代文本和下载按钮。
- 视频继续使用原生控件且不自动播放。
- 组件测试断言图片使用受约束的 `object-contain`。
- Playwright 在 `1440x900` 和 `390x844` 验证完整可见画幅、黑色留边与无布局溢出。
