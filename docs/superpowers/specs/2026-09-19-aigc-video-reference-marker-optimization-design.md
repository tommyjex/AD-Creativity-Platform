# AIGC 画布视频参考标记优化设计

## 背景

AIGC 画布的 `video_generation` 节点支持在提示词中使用
`(参考@图N)`、`(参考@视频N)` 和 `(参考@音频N)` 标记来指向已连接的参考媒体。
提示词优化时，这些标记内的序号会被通用字面量校验识别为必须完全保留的数字。
模型对标记进行删改、移动或省略时，后端会拒绝原本可用的优化结果，并将其表现为
优化失败。

本次目标是在尽量保持参考标记的同时，让它们不再成为视频提示词优化的阻断条件。

## 范围

仅覆盖 AIGC 画布的 `video_generation` 提示词优化链路：

- 前端 `aigc-prompt-editor` 的视频优化弹窗；
- 后端 AIGC 视频优化请求的模型指令；
- `validate_prompt_optimization_result` 中视频提示词的通用字面量校验。

不修改分镜视频优化、视频生成执行、参考媒体连接、图片提示词优化或公开 API
响应契约。

## 设计

### 参考标记保留策略

`(参考@图N)`、`(参考@视频N)`、`(参考@音频N)` 是视频提示词中的软约束：

1. 发送给模型的优化指令明确要求原样保留用户已有的上述标记。
2. 返回结果继续直接作为优化提示词写回，不在服务端补写、重排或替换标记。
3. 标记的出现次数、序号、顺序或位置发生变化时不抛校验错误，不将优化请求降级为
   失败。

这保证模型仍能获得清晰的保留目标，同时避免后端用确定性规则否决可用创作结果。

### 视频校验边界

视频提示词的通用字面量校验在比较输入和优化结果时，先忽略标准参考标记本身，
以及这些标记中的序号。其余现有校验继续按当前语义执行。

以下最小结构性失败条件保持不变：

- Provider 响应无法解析为提示词优化结果；
- 非图片目标返回图片专用的引用说明结构；
- 优化结果没有任何可写回的内容。

不新增任何与参考标记相关的硬校验、自动修复或用户确认。

### 编辑器提示

视频节点被选为优化目标时，在弹窗的提示词编辑区域附近显示一条简洁说明：

> 优化会尽量保留提示词中的参考媒体标记。

该说明不展示校验状态、不阻止提交，也不要求用户调整标记。

## 数据流

1. 用户在文本节点中输入含参考标记的视频提示词，打开提示词优化弹窗。
2. 前端识别目标为 `video_generation`，显示软保留说明并提交原始提示词。
3. 后端构造视频优化模型指令，将已有标准参考标记作为需原样保留的优先指令。
4. 模型返回优化文本。
5. 后端执行现有结果解析与最小结构性检查；参考标记不参与硬性字面量匹配。
6. 前端将成功结果照常展示并允许写回。

## 测试与验收

- 后端单元测试验证含图、视频、音频标记的输入，即使模型结果删改这些标记也能成功
  返回。
- 后端单元测试验证视频优化的模型指令包含“原样保留已有参考标记”的要求。
- 回归测试验证普通字面量校验和空结果拒绝行为不被放宽。
- 前端组件测试验证视频优化目标展示说明，LLM 与生图目标不展示该说明。
- 运行提示词优化相关后端测试和前端提示词编辑器测试。
- 重启后端后使用实际 AIGC 画布请求复测，并通过现有调试埋点比对修复前后的
  解析/校验错误路径。

## 不在范围

- 不保证模型一定保留、修复或重新插入任何参考标记；
- 不改变参考媒体是否实际连接到视频节点的校验；
- 不新增 API 字段、警告码或持久化数据；
- 不清理当前调试埋点和调试会话，直至用户确认实际复测成功。
