# AIGC 画布工具栏国庆底图设计

## 背景

AIGC Pipeline 编辑器顶部工具栏当前使用近黑色纯色背景。全局导航已经采用正红丝绸与
暖金星光主题，本次将同一视觉资产延伸到画布顶部工具栏，使两个顶部区域保持一致，
同时保留画布工作区的深色专业界面。

## 目标

- 仅将 AIGC 画布顶部工具栏替换为正红丝绸与暖金星光底图。
- 复用现有本地资源 `navigation-national-day-red.webp`，不新增重复资产。
- 保证标题、模式标识和操作按钮在复杂底图上清晰可读。
- 保持工具栏尺寸、布局、功能和响应式行为不变。

## 非目标

- 不修改节点画布、节点库、详情栏或页面外层背景。
- 不修改全局导航及其他业务页面。
- 不调整工具栏按钮的功能、顺序或尺寸。
- 不新增动画、文字、Logo 或节庆装饰组件。

## 视觉方案

工具栏继续使用 `56px` 固定高度。底层设置正红回退色，并以
`/images/navigation-national-day-red.webp` 居中铺满：

- `background-position: center`
- `background-repeat: no-repeat`
- `background-size: cover`

底图上叠加低透明度深红遮罩，压低丝绸高光和星芒对内容的干扰。遮罩只负责对比度，
不改变图片的正红主色。现有 `ToolbarStarMap` 继续保留，使工具栏与 AIGC 模态色彩体系
保持关联。

标题与命令区继续位于装饰层上方。按钮现有深色或蓝色状态保持不变，避免扩大本次修改
范围；底图的暖金元素作为节庆点缀，不改变业务操作的状态语义。

## 代码范围

### `frontend/components/workspace/aigc/aigc-editor.tsx`

- 将 `aigc-editor-header` 的纯色背景替换为正红回退色和本地底图。
- 增加无交互的深红遮罩层。
- 保留标题区、星图和命令区的现有层级与交互。

### `frontend/tests/aigc-editor.test.tsx`

- 更新工具栏样式断言。
- 增加底图路径、铺设方式和遮罩层断言。
- 保留画布仍为 `bg-[#101318]` 的断言，防止主题误扩展。

### `frontend/scripts/verify-aigc-workbench-layout.mjs`

- 在四个既有视口检查工具栏底图加载成功。
- 检查工具栏背景图、回退色和遮罩存在。
- 保留画布近黑背景、布局、面板和交互验收。

## 可访问性与失败处理

- 装饰遮罩使用 `aria-hidden="true"` 和 `pointer-events-none`。
- 底图加载失败时回退为正红纯色，工具栏仍可读、可操作。
- 不改变按钮的可访问名称、键盘操作和焦点行为。
- 不改变隐藏的自动保存状态播报。

## 验证

1. 运行 AIGC 编辑器组件测试。
2. 运行 TypeScript 检查和 ESLint。
3. 运行 AIGC 工作台专项 Playwright 四视口验收。
4. 检查桌面、阈值、平板和手机截图，确认工具栏呈现正红丝绸与暖金星光。
5. 确认节点画布、节点库和详情栏仍保持原有深色背景。
6. 确认工具栏内容无重叠、溢出或可读性退化。

## 验收标准

- AIGC Pipeline 与模板编辑器顶部工具栏使用现有正红丝绸与暖金星光底图。
- 底图仅作用于工具栏，不扩展到画布、侧栏或其他页面区域。
- 工具栏高度、布局、按钮状态和交互行为保持不变。
- 图片失败时回退为正红背景，控件仍清晰可用。
- 桌面、平板和手机视口无文字遮挡、重叠或横向溢出。
- 组件测试、类型检查、Lint 和专项 Playwright 验收通过。
