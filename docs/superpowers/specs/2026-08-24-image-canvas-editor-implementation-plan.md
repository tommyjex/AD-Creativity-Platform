# 图片画布编辑器实施计划

1. 在前端 API 类型中增加参考图区域、编辑模式和多参考图替换字段，保持现有单图请求兼容。
2. 新建 `ImageCanvasEditor`：
   - 使用现有归一化坐标函数处理目标图和参考图的 bbox。
   - 提供单图编辑与参考图替换模式、参考图选择、区域清除和结构化引用。
   - 在桌面使用目标画布和固定指令栏双栏布局；窄屏改为纵向布局。
   - 根据结构化状态给出可恢复的禁用原因。
3. 将图片版本卡片“编辑图片”入口改为打开画布编辑器；提交后继续通过现有任务轮询刷新项目和版本。
4. 增加前端组件和工作区测试，覆盖模式、请求映射、区域校验及布局标识。
5. 运行后端多参考图回归和前端 lint、typecheck、定向 Vitest；更新 spec 任务清单。

## 图层内容编辑

1. 新增图层内容编辑请求、冻结输入和 repository 原子替换接口。
2. 提交图层内容编辑任务，调用 Seedream 图生图并以 revision 保护替换内部资产引用。
3. 在图层编辑器为非底图提供编辑指令、任务轮询、冲突反馈和刷新。
4. 覆盖冻结、原资产追溯、冲突不覆盖、前端入口与移动端布局验证。
