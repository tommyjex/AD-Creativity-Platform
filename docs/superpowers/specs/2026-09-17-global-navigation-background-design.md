# 全局导航栏背景底图设计

## 背景

当前全局导航栏使用近乎纯白的半透明背景，与下方深色 AIGC 节点画布形成明显割裂。导航右侧的 `BRIEF READY` 和“进入工作台”没有提供独立于主导航的有效能力，反而造成三段式布局松散、横向空间利用不均。

本设计采用视觉对比方案 C：在不增加导航高度、不新增独立 Banner 的前提下，为现有导航加入暗色电影感背景底图，并让导航直接衔接下方深色工作区。

## 目标

- 为全部非全屏页面提供统一的暗色背景图导航。
- 删除 `BRIEF READY` 和“进入工作台”两个无效操作。
- 优化桌面端导航布局，消除删除右侧操作后产生的空区。
- 在移动端提供可操作的导航菜单。
- 保持现有路由、当前项判断和全屏编辑器例外不变。

## 非目标

- 不增加 Banner 区域或改变页面内容的顶部偏移。
- 不修改项目、资产库、工具或 AIGC 工作台页面主体。
- 不改变现有导航路由。
- 不在背景图中生成文字、Logo 或产品品牌。
- 不为全屏图层编辑器和全屏时间线编辑器恢复全局导航。

## 视觉方向

### 背景底图

导航背景使用横向暗色电影感图像：

- 主材质为深石墨、黑色玻璃和精密机械表面。
- 使用细窄电蓝色光迹作为主强调。
- 少量加入橙色、绿色和玫红信号点，呼应画布中的视频、图片和音频模态色。
- 保留大面积低细节负空间，避免与品牌和导航文字竞争。
- 图中不得包含文字、Logo、人物或可识别品牌。

背景图通过项目规定的 Seedream 图像接口生成，尺寸使用 `landscape_16_9`。导航中将其作为纯装饰背景，不提供替代文本。

### 对比度保护

背景图上覆盖固定深色渐变层：

- 左侧品牌区使用更高不透明度，保证品牌名称和副标题清晰。
- 中部导航区使用中等不透明度，保留图像质感。
- 右侧使用较深收尾，避免宽屏时出现突兀亮区。

背景图请求失败或未加载时，导航回退到 `#14191f` 纯色背景，所有文字和交互仍保持可用。

## 布局

### 桌面端

- 导航保持固定定位和 `64px` 高度。
- 容器继续使用现有全局 `container` 宽度。
- 品牌标识左对齐。
- “项目 / 资产库 / 工具 / AIGC工作台”导航胶囊整体右对齐。
- 删除 `BRIEF READY` 和“进入工作台”，不保留占位。
- 使用 `justify-between` 建立清晰的左右双区布局。
- 导航胶囊使用半透明深灰背景和细边框，并启用适度背景模糊。
- 非当前项使用中灰文字；悬停时提升为浅色并增加轻微背景。
- 当前项使用蓝色半透明实底和白色文字。

### 移动端

- 保持 `64px` 高度和品牌左对齐。
- 桌面导航胶囊在小于 `md` 断点时隐藏。
- 右侧显示 Lucide `Menu` 图标按钮；菜单打开时切换为 `X` 图标。
- 点击图标后，在导航栏下方打开暗色浮层，纵向显示四个导航入口。
- 当前入口使用与桌面一致的蓝色高亮。
- 点击入口、再次点击菜单按钮或路由发生变化时关闭菜单。
- 菜单浮层宽度在手机上贴合左右安全间距，不使用全屏遮罩。

### 平板端

- `md` 及以上沿用桌面胶囊导航。
- 导航文字和内边距保持紧凑，避免与品牌区域重叠。

## 组件结构

主要修改 `frontend/components/layout/app-shell.tsx`：

- `AppShell` 继续负责全屏路由例外和全局壳层。
- `navItems` 继续作为桌面和移动导航的唯一数据源。
- 导航背景拆为绝对定位的图像层和渐变遮罩层。
- 桌面导航复用现有链接渲染逻辑。
- 新增局部 `MobileNavigationMenu`，只处理菜单开关和移动导航链接。

不引入新的菜单依赖。移动菜单使用 React 状态、Lucide 图标和语义化按钮实现，避免为了单一菜单增加 UI 库。

## 交互与可访问性

- 移动菜单按钮使用 `aria-label`、`aria-expanded` 和 `aria-controls`。
- 移动菜单容器使用稳定 ID，并包含可键盘访问的普通链接。
- 当前路由继续通过 `aria-current="page"` 标识。
- 菜单按钮保持至少 `40px × 40px` 点击区域。
- 导航文字与背景的对比度目标不低于 WCAG AA。
- 背景图层设置 `aria-hidden="true"` 且不响应指针事件。
- 路由切换后移动菜单自动关闭，避免新页面保留旧浮层。

## 状态与失败处理

- 页面首次加载时立即显示深色回退背景，图片加载完成后自然覆盖，不出现白色闪烁。
- 背景图不可用时不显示破图图标。
- 移动菜单状态仅存在于 `AppShell` 内，不写入全局状态或本地存储。
- 全屏图层/时间线编辑器仍直接返回沉浸式壳层，不创建背景或移动菜单状态。

## 测试

### 组件测试

- 不再渲染 `BRIEF READY` 和“进入工作台”。
- 桌面导航仍包含四个既有入口。
- 当前路由仍正确设置 `aria-current`。
- 移动菜单按钮包含正确 ARIA 属性。
- 点击菜单按钮可展开和关闭菜单。
- 点击移动导航入口后菜单关闭。
- 路由变化后菜单关闭。
- 全屏编辑器路由仍不渲染全局导航。

### 浏览器验收

使用 Playwright 检查：

- 桌面宽屏、普通桌面、平板和手机视口。
- 背景底图已加载且导航非纯白。
- 品牌、导航项和当前项文字清晰。
- 桌面导航左右布局无重叠。
- 手机菜单在视口内完整显示，文字不溢出。
- 导航保持 `64px` 高度，页面主体仍使用 `pt-16`。
- 导航与 AIGC 深色画布衔接自然。
- 图片加载失败回退状态仍可读、可操作。

## 验收标准

- 所有非全屏页面显示方案 C 暗色背景图导航。
- 导航高度和页面顶部偏移不变。
- `BRIEF READY` 和“进入工作台”完全移除。
- 桌面端品牌在左、导航在右，布局无无效空位。
- 移动端可通过菜单图标访问全部四个入口。
- 背景失败时有稳定深色回退。
- 全屏编辑器行为不变。
- 相关测试、TypeScript、ESLint 和多视口 Playwright 验收通过。
