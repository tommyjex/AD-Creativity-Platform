# AIGC 图层编辑器全屏沉浸黑灰设计

## 目标

将独立图层画布编辑器调整为与 AIGC 主画布一致的层级黑灰工作台，并在该路由隐藏全局导航，把完整视口交给图层编辑任务。

## 视觉层级

- 页面背景与画布舞台使用近黑色 `#0b0d10` / `#0d1014`，移除当前浅色径向渐变。
- 编辑器顶栏使用 `#15181d`，左侧工具栏使用 `#14171b`，右侧图层与属性栏使用 `#171a1f`。
- 图层条目和输入控件使用稍亮的 `#1d2127`，边界使用低对比灰 `#2a3038`。
- 主文字使用近白色，辅助信息使用中性灰；不使用大面积蓝色或彩色渐变。
- 作品画布保持图片原色和原始宽高比，通过深色阴影与工作区分离。
- 蓝色只用于选中框、当前图层、激活工具和“保存到节点”主操作。

## 全屏路由

- 路径 `/workspace/aigc/pipelines/{pipelineId}/nodes/{nodeId}/layers` 进入全屏沉浸模式。
- `AppShell` 在该路径隐藏全局品牌导航和装饰背景，并移除内容区顶部 `4rem` 偏移。
- 图层编辑器根容器改用完整 `100dvh`；其他工作区页面保持现有全局导航和布局。
- 浏览器刷新、直接访问和返回 AIGC 画布的路由行为不变。

## 编辑器布局

- 顶栏保留返回、标题、Pipeline 信息、放弃修改和保存到节点。
- 桌面端继续使用“固定左工具栏 + 弹性中央舞台 + 固定右侧栏”三栏结构。
- 左侧工具按钮使用深灰底与低对比边界；激活、悬停和禁用状态清晰可辨。
- 右侧图层列表保持高信息密度，选中项使用克制的蓝色边界和深蓝灰背景，不使用嵌套浮动卡片效果。
- Transform 区和保存状态区与图层列表共用右侧栏层级，通过细边界分区。
- 缩放百分比作为画布内浮动状态显示，采用深色半透明底，不遮挡作品主体。

## 响应式

- 桌面端保持三栏固定结构，中央舞台优先获得剩余空间。
- 小于 `1024px` 时继续使用现有纵向布局：顶部工具栏横向滚动、画布区域保持最低高度、右侧内容移动到画布下方。
- 小屏顶栏允许换行，返回、放弃和保存按钮保持可访问且不重叠。
- 全屏模式在所有断点均不恢复全局导航。

## 状态与兼容

- 加载页和错误页同步采用全屏黑灰背景，避免页面切换时闪现浅色区域。
- 保存中、保存失败、Revision 冲突、图层资产加载失败继续使用现有状态与文案。
- 不修改图层选择、移动、缩放、排序、显隐、删除、撤销、重做和保存数据流。
- 不修改 Pipeline definition、API、后端模型或自动保存契约。

## 验证

- `AppShell` 测试覆盖图层编辑路由隐藏全局导航，普通工作区路由继续显示导航。
- 图层编辑器测试覆盖完整视口、黑灰层级类、无浅色径向渐变及现有响应式布局。
- 既有图层交互、保存、冲突和资产失败测试全部通过。
- TypeScript、ESLint、完整 Vitest 和生产构建通过。
- Playwright 在桌面和移动视口检查全屏占用、无浅色漏底、控件可达、文本无重叠及控制台无新增错误。
