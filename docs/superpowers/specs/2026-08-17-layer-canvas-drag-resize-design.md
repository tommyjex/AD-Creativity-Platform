# 图层画布拖拽等比缩放设计

## 目标

图层编辑器中，用户选择可见图层后，可直接在画布上拖动右下角手柄等比例放大或缩小该图层。保留现有图层主体拖动、右侧缩放控件、保存 revision 和合成导出行为。

## 已确认方案

采用方案 A「单手柄 / 左上固定」：

- 当前选中图层继续显示蓝色轮廓。
- 仅在选中且可见的图层右下角显示一个缩放手柄。
- 拖动图层主体仍移动图层。
- 拖动缩放手柄只改变 `scale`，不改变 `x/y`。
- 左上角是固定锚点，与现有后端 `{x, y, scale}` 合成语义一致。
- 缩放范围沿用 `0.05–20`，右侧滑杆和数值框与画布手柄实时同步。

## 交互与计算

手柄使用 Pointer Events 并独立捕获指针，阻止事件冒泡到图层移动逻辑。拖动距离投影到图层原始宽高形成的对角线上，再换算为统一 `scale`，因此横向、纵向或斜向拖动都不会改变宽高比。

缩放开始时冻结：

- 图层 ID 和初始 `scale`；
- 指针起点；
- 图层原始 bbox 尺寸；
- 画布当前渲染尺寸。

拖动中只更新前端草稿。Pointer Up 或 Pointer Cancel 后结束缩放；保存时继续通过现有 `ImageLayerSetUpdate` 提交完整图层状态。

## 边界

- 隐藏图层不显示手柄。
- 未选中图层不显示手柄。
- 拖动结果低于或高于合法范围时钳制到 `0.05` 或 `20`。
- 画布尺寸无效时保持原始缩放值。
- 不新增后端字段、数据库迁移或 API。
- 不增加旋转、裁剪、自由拉伸、多选或中心缩放。

## 验证

- 纯函数测试缩放投影、上下限和无效画布尺寸。
- 组件测试选择图层、拖动手柄、`scale` 数值同步，以及 `x/y` 不变。
- 回归图层主体移动、显隐、排序、保存 revision、冲突重载和导出。
- Playwright 验证桌面画布交互及移动端布局无溢出。
