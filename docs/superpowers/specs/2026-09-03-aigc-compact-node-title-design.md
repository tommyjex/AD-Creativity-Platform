# AIGC 紧凑节点标题设计

## 目标

移除节点顶部的浅色标题栏视觉，只保留无底色的紧凑节点名称，使节点与深色画布保持一致。

## 设计

- 标题行高度为 28px，标题使用 11px 中等字重。
- 移除标题行背景色、底部分隔线和节点类型图标。
- 节点名称保持单行截断，并继续作为稳定拖拽区域。
- 删除按钮从节点移除；用户通过选中节点后按 `Delete` 或 `Backspace` 删除。
- 下载和图片精准编辑属于独立功能入口，默认隐藏，在标题行悬停或键盘聚焦时显示，避免功能丢失。
- 整个节点底栏移除；节点类型、运行状态和节点 ID 改由右侧详情栏查看。
- 节点外框继续使用模态颜色，选中状态与连接端口行为保持不变。

## 验证

- 节点单测验证标题行无背景、无分隔线、无类型图标和删除按钮。
- 节点单测验证标题字号为 11px，且不再渲染底栏元数据。
- 节点单测验证下载与精准编辑入口仍可访问。
- 前端全量测试、类型检查、Lint 和生产构建通过。
- 浏览器截图确认标题行与深色节点融为一体，文字和操作不重叠。
