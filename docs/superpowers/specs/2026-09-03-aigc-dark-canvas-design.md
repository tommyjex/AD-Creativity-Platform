# AIGC 深色画布设计

## 目标

将 AIGC 编辑器调整为方案 B 的层级黑灰工作台：画布使用近黑背景，顶部栏、节点库和详情栏使用略亮的深灰表面，并把顶部命令收敛到核心操作。

## 视觉层级

- 编辑器外壳与画布：`#101318`，使用低对比灰色点阵。
- 顶部栏：`#171a1f`，底部使用细灰色边界。
- 节点库和详情栏：`#181b20`，与画布形成轻微明度差。
- 工具按钮和画布工具坞：`#20242a`，悬停时提高一个灰阶。
- 主操作“执行”继续使用蓝色强调；节点继续使用现有模态颜色。
- 深色主题仅作用于 AIGC 编辑器，不修改全局主题和其他画布。

## 顶部栏

Pipeline 模式只显示：

1. 返回
2. 详情
3. 另存为模板
4. 执行

模板模式只显示可用的返回和详情。撤销、重做与运行记录不再占用顶部空间；运行记录仍通过详情栏的“运行”标签访问。自动保存逻辑保持不变，并保留屏幕阅读器状态播报，但不再显示视觉 Badge。

## 响应式行为

- 桌面端维持 184px 节点库、按需展开的 320px 详情栏和底部居中的画布工具坞。
- 窄屏继续使用节点库与详情栏互斥浮层。
- 顶部栏在所有断点保持单行；另存为模板和执行在窄屏仅显示图标。

## 验证

- Vitest 固定顶部命令集合、模板差异、深色类名和现有面板状态。
- TypeScript、ESLint 和生产构建必须通过。
- Playwright 在 1440、1024、768、390 四个视口验证深色背景、命令不溢出、面板交互与控制台无错误。
