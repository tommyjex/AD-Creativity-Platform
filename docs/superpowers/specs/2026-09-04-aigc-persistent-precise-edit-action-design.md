# AIGC 图片精准编辑按钮常驻设计

## 目标

让图片输入节点的“精准编辑”入口无需悬停即可发现，同时保持紧凑标题栏和其他节点操作的低干扰视觉。

## 交互

- 图片输入节点始终显示“精准编辑”图标按钮。
- 尚未选择图片时，按钮保持可见但处于禁用状态，提示“选择图片后可精准编辑”。
- 已选择图片时，按钮可用，点击后继续打开现有精准编辑弹窗。
- 输出节点的下载按钮继续仅在标题栏悬停或键盘聚焦时显示。
- 非图片输入节点不新增常驻操作。

## 实现边界

- 仅调整 `AigcFlowNode` 标题栏中操作按钮的可见性分组。
- 不修改精准编辑弹窗、框选数据、节点配置或自动保存逻辑。
- 不改变节点标题栏高度、节点尺寸和下载行为。

## 测试

- 图片输入节点无图片时，精准编辑按钮在默认状态下可见且禁用。
- 图片输入节点有图片时，精准编辑按钮在默认状态下可见且可打开弹窗。
- 下载按钮仍保留悬停/聚焦显示样式。
- 运行 AIGC 节点定向测试、TypeScript 与 ESLint 检查。
