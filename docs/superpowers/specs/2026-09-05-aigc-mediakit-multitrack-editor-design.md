# AIGC 画布 MediaKit 多轨剪辑设计

## 目标

在 AIGC 工作台中新增一个“多轨剪辑”执行节点，并提供独立全屏时间线编辑器。AIGC 画布负责素材依赖、执行顺序和结果流转；时间线编辑器负责画布、轨道、片段、文字、字幕和基础效果编排；最终成片由 AI MediaKit 多轨道剪辑异步 API 合成。

## 产品边界

首版支持：

- 视频、图片、音频、文字和 SRT 字幕轨道。
- 轨道新增、删除、重命名、排序、隐藏、静音。
- 片段拖拽、缩放时间轴、吸附、分割、左右裁切和时间数值编辑。
- 视频/图片/文字的 2D Transform。
- 视频/音频的倍速、音量和淡入淡出。
- 同一视频轨道相邻片段的转场。
- 自定义画布宽高与背景色。
- MP4 输出和帧率设置。

首版不支持 LUT 调色、视觉特效、文字动画、滚屏文字、局部模糊、高斯模糊、关键帧动画、自定义字体上传、AIGC 元数据编辑、逐帧精确预览或仅音频导出。

## 画布节点

新增执行节点 `multi_track_edit`：

- 输入 `videos: video_asset`，多值，最多 30 条连接。
- 输入 `images: image_asset`，多值，最多 50 条连接。
- 输入 `audios: audio_asset`，多值，最多 30 条连接。
- 输入 `texts: text`，多值，最多 30 条连接。
- 输出 `video: video_asset`。

节点卡片展示轨道数、元素数、总时长、画布尺寸、输出帧率、保存状态和最近运行结果。节点上的“编辑时间线”操作进入：

`/workspace/aigc/pipelines/{pipelineId}/nodes/{nodeId}/timeline`

该路由与图层编辑器一样隐藏全局导航并占满 `100dvh`。

## 素材来源

- 视频、图片和音频元素只能绑定该剪辑节点的直接上游模态节点或模型输出。
- 文字元素可以绑定直接上游文本节点，也可以保存内联文本。
- SRT 字幕由时间线编辑器上传，保存为项目 `subtitle` 资产，并由 Pipeline 资产关系保护。
- 时间线配置不持久化公网 URL、临时签名 URL或 MediaKit URL。
- 上游元素保存稳定的 `source_node_id + source_handle`。执行时从当前 RunNode 解析资产 ID 或文本，再生成受控可访问 URL。
- 一个上游素材可以在时间线中被重复使用；删除画布入边后元素保留为“来源缺失”草稿，保存允许，执行禁止。

## 剪辑工程模型

`MultiTrackEditConfig` 保存：

- `canvas`: `mode=auto|custom`、宽、高、RGBA 背景色。
- `output`: 固定 `format=mp4`，帧率。
- `tracks`: 最多 20 条轨道、合计最多 200 个元素。
- 每条轨道包含稳定 ID、名称、类型、排序、隐藏/静音状态和元素列表。
- 每个元素包含稳定 ID、类型、来源、`target_time`、循环和类型专属参数。

元素类型：

- `video`: 上游视频、目标时间、源裁切、循环、Transform、倍速、音量、淡入淡出、转场。
- `audio`: 上游音频、目标时间、源裁切、循环、倍速、音量、淡入淡出。
- `image`: 上游图片、目标时间、循环、Transform。
- `text`: 上游文本或内联文本、目标时间、基础字号/颜色/粗斜体/下划线/背景、Transform。
- `subtitle`: SRT 资产、目标时间、基础字体样式、Transform；每条字幕轨道只允许一个元素，字幕轨道最多 10 条。

时间统一使用整数毫秒。轨道数组从下到上对应 MediaKit `track[][]` 的渲染层级。

## 编辑器布局

- 顶栏：返回画布、标题、Pipeline、保存状态、撤销、重做、放弃修改、执行剪辑。
- 上半区：左侧输出画布预览，右侧选中轨道/元素检查器。
- 下半区：轨道控制区、时间标尺、播放头和可横向缩放的时间线。
- 左侧轨道头支持重命名、排序、隐藏、静音和删除。
- 片段支持拖拽移动、拖动两端裁切、分割、选择与删除。
- 时间线支持吸附到播放头、相邻片段边界和整秒刻度。
- 检查器提供精确时间和参数输入，所有拖拽结果最终规范化为整数毫秒。
- 浏览器预览用于布局和节奏检查，不承诺与 MediaKit 的转场、音频混合和字体渲染逐帧一致；已合成结果是最终权威预览。

桌面端保持“预览 + 检查器 / 时间线”结构。小于 `1024px` 时检查器进入互斥抽屉，时间线保持横向滚动；移动端保留数值编辑和基础拖拽，不要求逐帧精度。

## 校验

保存允许不完整草稿，但执行前必须满足：

- 至少一条非隐藏轨道和一个有效元素。
- 轨道与元素 ID 唯一，数量不超过产品上限。
- `target_time=[start,end]` 为非负整数且 `start < end`。
- 同轨元素不重叠；仅带转场的相邻视频允许按转场时长重叠。
- 素材来源必须对应当前节点直接入边，Run 中结果可用且 MIME 与元素类型一致。
- 源裁切区间有效；裁切后经倍速换算的持续时间与目标时间一致。
- 倍速范围 `[0.1,4]`，音量非负，淡入淡出不超过元素时长。
- Transform 必须位于自定义或解析后的画布范围内。
- 自定义画布宽高均为 `[160,8192]`，背景色为 RGBA 十六进制。
- 文字和字幕必须有 Transform；SRT 必须是成功、可访问且 MIME/扩展名合法的字幕资产。
- 转场只作用于同轨相邻视频，保存在前一个元素，时长不得超过相邻片段可用区间。

前端提供即时错误提示；后端在保存规范化后和执行前进行等价权威校验。非法时间线不得调用 MediaKit。

## MediaKit 执行

- 新增隔离客户端调用 `POST /api/v1/tools/multi-track-edit`，使用现有 Bearer API Key。
- 使用稳定 `client_token` 保证同一 Task Attempt 的提交幂等。
- 复用 `GET /api/v1/tasks/{task_id}` 轮询，映射排队、运行、完成、失败、非法响应和超时。
- 提交前将稳定来源解析为受控 URL，构造白名单化 `canvas / track / output`，不发送 callback、queue 或供应商直存参数。
- 完成后立即将 24 小时临时 URL 流式转存到本系统对象存储，登记公开 `video` 输出资产。
- 元数据记录 `provider=mediakit`、`operation=multi_track_edit`、供应商任务/请求 ID、轨道数、元素数、时长、分辨率、帧率和 executor version。
- 不持久化 API Key、完整供应商响应或签名 URL。

多轨剪辑使用独立并发槽、轮询间隔、任务超时和转存限制。缓存 Hash 包含规范化剪辑工程、所有有效上游摘要和字幕资产摘要。重试使用冻结任务快照。

## 保存与冲突

- 编辑器加载 Pipeline 当前 revision 和节点配置。
- “保存到节点”使用 `expected_revision` 乐观并发。
- Revision 冲突时不覆盖远端，提示返回画布重新加载或放弃本地修改。
- “执行剪辑”先保存；保存成功后从该节点发起 Run。
- 撤销/重做只作用于本地剪辑工程，不修改画布连接。

## 状态与错误

- 节点与编辑器展示保存中、保存失败、来源缺失、校验失败、排队、运行、转存、成功、失败、取消和缓存复用。
- 错误阶段区分 `validate / submit / poll / transfer / persistence`。
- 供应商错误经过脱敏，不暴露密钥、签名 URL 或原始响应。
- 取消、Worker 租约、晚到结果保护、失败重试、从节点继续和独立分支收敛沿用现有 AIGC 语义。

## 验证

- 前后端契约与时间线校验使用参数化测试覆盖边界。
- MediaKit 客户端使用 Mock Transport，自动化不调用真实计费接口。
- 执行器测试覆盖多输入解析、Hash、重试、取消、缓存、转存和资产追溯。
- 前端测试覆盖时间线编辑、撤销重做、保存冲突和响应式布局。
- Playwright 在 `1440x900`、`1023x768`、`390x844` 验证节点、全屏路由、拖拽、裁切、分割、检查器、执行、结果播放和无重叠。
