# 星图创作台画布列表页重设计

## 目标

按照用户提供的“星图创作台”参考稿，重设计 AIGC 画布列表页及全站共享顶部
导航，使页面形成深色、克制、青绿色聚焦的创作工作台风格。

本次只调整视觉层与响应式结构，保留现有业务能力、接口契约、权限逻辑和数据模型。

## 范围

### 包含

- 重设计全站共享顶部导航，并应用于项目、资产库、工具和 AIGC 工作台。
- 重设计“星图创作台”标题区、操作栏、卡片网格和页面状态。
- 统一模板卡与画布卡的视觉层级。
- 适配桌面、平板和移动端。
- 更新相关组件测试与浏览器验收。

### 不包含

- 不修改画布编辑器内部导航、节点画布、时间线或图层编辑器。
- 不新增排序、筛选类型或服务端查询能力。
- 不修改 API、数据库或后端数据模型。
- 不改造其他页面的主体内容。
- 不引入新的字体、动画或设计系统依赖。

## 设计方向

页面采用接近参考稿的高还原布局：

- 深黑主背景和略亮的深色卡片表面。
- 青绿色作为唯一主操作与激活态颜色。
- 状态使用已有语义色，不将页面处理成单一青绿色主题。
- 使用清晰边框、轻量阴影和有限悬浮位移建立层级。
- 卡片圆角不超过 8px；胶囊形态只用于数量和状态。
- 保持高信息密度，不采用营销页式大幅留白或装饰性卡片嵌套。

## 全站顶部导航

共享导航继续由现有 App Shell 承载，不创建 AIGC 专用副本。

桌面端结构：

1. 左侧显示品牌图标、`AD CREATIVITY` 和
   `CAMPAIGN GENERATION DECK`。
2. 中部或品牌右侧显示项目、资产库、工具、AIGC 工作台入口。
3. 当前栏目使用青绿色文字和低饱和深绿背景高亮。
4. 右侧保留当前用户入口和既有权限相关行为。

移动端继续使用现有汉堡菜单收纳主导航，不把全部导航项挤入一行。

导航从当前节日红色主题恢复为持久的深色工作台主题。此次变更作用于所有使用共享
App Shell 的页面，但不改变各页面主体内容。

## 页面结构

### 标题区

内容放入宽屏居中容器，最大宽度约为 `1400px`：

- 英文眉题：`DAG CREATION WORKSPACE`。
- 主标题：`星图创作台`。
- 说明：`从模板快速建立生成流程，或维护可重复执行的节点画布。`
- 当前视图总数显示在标题区右侧，使用紧凑胶囊样式。
- 只读提示放在说明下方，不改变权限语义。

### 操作栏

操作栏位于标题区下方：

- 左侧使用分段控件切换“画布模板”和“我的画布”。
- 右侧依次放置名称搜索、筛选按钮和“新建空白画布”。
- 清空筛选继续使用现有图标按钮。
- 无写权限时隐藏创建入口。
- 中小屏允许工具栏换行，移动端按垂直顺序排列。

搜索仍由表单提交触发，不改为输入即请求。

## 卡片

### 布局

- 宽桌面：4 列。
- 普通桌面或平板横屏：3 列。
- 平板：2 列。
- 手机：1 列。
- 卡片使用稳定的预览宽高比，动态内容不得引起网格跳动。

### 预览

采用 A1 策略：

1. 画布存在选定图片或视频缩略图时，展示真实媒体。
2. 图片和视频使用固定媒体区与 `object-contain`，保持原始宽高比，禁止裁切或拉伸。
3. 缩略图缺失或加载失败时，显示现有节点拓扑预览。
4. 模板始终使用拓扑预览。

缩略图管理按钮保留为图标按钮，并提供 tooltip 与可访问名称。

### 信息

卡片内容顺序：

1. 名称与运行状态。
2. 最多两行说明，空值显示“未填写说明”。
3. 节点数量、模型数量和更新时间。
4. 整行主命令按钮：“使用模板”“查看模板”或“打开画布”。

删除、编辑模板和选择缩略图等工具操作继续使用图标按钮。工具按钮必须阻止卡片打开
事件冒泡。

卡片悬浮时仅提高边框、阴影和少量位移；键盘焦点使用等价的青绿色可见焦点态。

## 状态与弹窗

以下行为保持不变，只统一为新视觉：

- 初次加载和翻页加载。
- 请求错误与重试。
- 无数据和无搜索结果。
- 新建空白画布弹窗。
- 删除模板或画布确认弹窗。
- 缩略图选择弹窗。
- 创建、实例化和删除进行中状态。

错误信息继续使用现有用户可读错误转换，不吞掉服务端错误。

## 数据与权限

现有数据流不变：

1. 页面使用初始模板与画布分页数据渲染。
2. 切换视图、搜索和分页继续调用现有查询。
3. 创建、模板实例化、删除和缩略图更新继续使用现有 mutation。
4. 成功后沿用当前缓存更新或页面导航逻辑。

只读用户：

- 不显示创建、删除和缩略图管理入口。
- 模板操作显示“查看模板”，不触发实例化。
- 仍可查看并打开其有权访问的内容。

Playwright 视口：

- 原有业务操作均可完成。
