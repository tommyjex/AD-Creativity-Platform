# AIGC Seedance 输入校验设计

## 目标

为 AIGC 生视频工作流建立可验证、不可绕过的媒体输入约束。新上传素材在进入资产库前完成真实内容探测；已有资产在连接或执行时按需补齐元数据；最终由后端在任务创建及供应商调用前按模型、生成模式和任务类型执行权威校验。

## 生视频任务类型

`video_generation` 配置新增：

- `generate`：生成新视频，作为旧画布默认值。
- `edit`：编辑参考视频。
- `extend`：延长参考视频。

任务类型仅在 `multimodal_reference` 模式展示。`edit` 与 `extend` 至少要求一个参考视频。切换到其他模式时保留配置但不参与请求；旧画布缺少字段时规范化为 `generate`。

任务类型用于选择输入视频时长规则，不改变输出视频时长配置：

- Seedance 2.5：`generate` 输入视频 2-30 秒，`edit/extend` 输入视频 4-30 秒。
- Seedance 2.0 系列：输入视频 2-15 秒。
- 输出时长继续使用现有 `-1`、4-30 秒或 4-15 秒规则。

## 分层校验

### 浏览器预检

- 根据扩展名、MIME 和 `File.size` 快速拒绝明显不支持的文件。
- 图片支持 JPEG、PNG、WebP、BMP、TIFF、GIF、HEIC、HEIF，单张严格小于 30 MB。
- 视频支持 MP4、MOV，单个不超过 200 MB。
- 音频支持 WAV、MP3，单个不超过 15 MB。
- 浏览器预检仅改善反馈速度，不能替代服务端校验。

### 上传时权威探测

- 图片读取真实格式、宽、高和宽高比；校验宽高 300-6000 px、比例 0.4-2.5。
- 视频使用 FFprobe 读取容器、视频编码、音频编码、宽、高、像素数、时长和 FPS。
- MP4/MOV 视频编码仅允许 H.264/AVC、H.265/HEVC。
- MP4 音频编码仅允许 AAC、MP3；MOV 音频编码仅允许 AAC、MP3、PCM；无音轨视频允许上传。
- 视频校验宽高 300-6000 px、比例 0.4-2.5、像素数 407696-8295044、FPS 24-60。
- 音频读取真实容器/编码和时长，仅允许 WAV、MP3。
- 探测结果使用稳定字段写入资产 metadata：`width`、`height`、`duration_seconds`、`fps`、`container`、`video_codec`、`audio_codec`、`inspection_version`。
- MOV 或浏览器不兼容编码可在验证通过后沿用现有规范化链路转换为 H.264/AAC MP4；原始和规范化信息分别记录，供应商校验以实际发送文件为准。

### 资产库旧素材

- 资产选择只展示 MIME 家族匹配的素材，并标记“可用 / 不兼容 / 需检测”。
- 缺少标准元数据的旧素材在选择或执行前从受控对象地址读取并探测一次，成功后持久化元数据。
- 无法访问或无法探测的素材不得进入执行，但不会从资产库自动删除。

### 节点与执行聚合校验

- 首帧模式固定一张首帧；首尾帧模式固定首、尾各一张。
- 全模态模式中图片数量在存在图片输入时：
  - Seedance 2.5：1-30。
  - Seedance 2.0 系列：1-9。
- Seedance 2.5：最多 10 个参考视频、10 段参考音频；各自总时长不超过 30 秒。
- Seedance 2.0 系列：最多 3 个参考视频、3 段参考音频；各自总时长不超过 15 秒。
- Seedance 2.5 音频单段 2-30 秒；Seedance 2.0 系列单段 2-15 秒。
- `edit/extend` 至少需要一个参考视频。
- 连接、模型切换、模式切换和任务类型切换时前端即时反馈；不静默删除现有边。
- 草稿允许保存不完整或不兼容状态，执行前必须通过后端完整校验。
- 网关在生成签名 URL 前再次校验资产状态、MIME 和标准元数据，防止绕过前端。

## 请求体与 Base64

本地上传继续使用二进制请求。供应商调用继续传受控签名 URL，不将大文件编码为 Base64，因此 64 MB 请求体限制不限制 200 MB 的视频文件本身；若未来增加 Base64 路径，必须单独实施 64 MB 聚合限制。

## 提示词反馈

- 配置面板按模型展示支持语言。
- 中文超过 500 字或英文超过 1000 词时显示建议性警告。
- 不自动拦截疑似不支持语言，不因长度警告阻止保存或执行。
- 后端继续保留现有最大字段长度与供应商错误处理。

## 错误反馈

- 上传失败返回具体字段及边界，例如“视频帧率 23.98 FPS，要求 24-60 FPS”。
- 节点聚合错误包含 node ID、素材类型和实际/允许值。
- 资产选择卡片显示不兼容原因，禁止确认不兼容素材。
- 执行期错误进入现有 AIGC task error 投影，不泄露对象签名或供应商原始响应。

## 验证

- 媒体探测单元测试覆盖格式、编码、尺寸、比例、像素数、FPS、大小和边界值。
- DAG/执行器测试覆盖任务类型、单段时长、数量上限、总时长、旧画布默认值和绕过前端。
- API 测试覆盖上传、旧资产补探测和结构化错误。
- 前端测试覆盖 accept、预检、资产兼容状态、任务类型控件和提示词警告。
- 后端在 `.venv` 下运行完整 pytest；前端运行完整测试、lint、typecheck 和 build。
- 浏览器验证上传失败反馈、模型/任务类型切换、资产卡片状态以及合法任务可保存但不触发真实付费生成。
