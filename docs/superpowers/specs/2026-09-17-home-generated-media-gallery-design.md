# 首页生成产物画廊设计

## 背景

当前首页承担 Brief 创建和产品能力说明，与用户进入系统后查看近期创作成果的主要需求不一致。本次重写将首页改为生成产物总览，让用户进入网站后直接浏览资产库中的公开图片和视频产物。

## 目标

- 汇总项目、工具和 AIGC 三类来源的全部公开生成图片与视频。
- 排除用户上传的参考素材、工具输入素材和内部中间资产。
- 将图片与视频分类展示，并以保留原始比例的瀑布流呈现。
- 支持点击缩略图放大查看图片或播放视频。
- 延续现有全局导航与暗色“均衡霓虹”视觉语言。

## 非目标

- 不在首页提供上传、删除、重命名或编辑能力。
- 不替代完整资产库的筛选、管理和分页功能。
- 不新增后端资产类型或修改资产持久化结构。
- 不展示音频、字幕、文本等非图片/视频资产。

## 信息架构

首页移除原有营销 Hero、能力卡片、流程说明和 Brief 表单，首屏直接呈现“创意产物”。

页面包含：

1. 标题区：显示页面标题、简短说明和图片/视频数量。
2. 分类控件：使用“图片 / 视频”分段控件，默认选中图片。
3. 搜索框：按当前展示名称过滤当前分类。
4. 瀑布流：按更新时间倒序展示当前分类的全部匹配产物。
5. 预览 Dialog：点击缩略图后查看原始比例图片或播放视频。

分类切换只替换瀑布流内容，不改变页面骨架或滚动上下文。桌面端使用多列瀑布流，移动端使用两列瀑布流；极窄视口允许降为单列，以保证最小可读宽度。

## 数据范围

首页复用现有资产查询能力，并在展示层统一聚合项目、工具和 AIGC 资产。

### 包含

- `asset_role === "public"` 或缺省为公开角色的资产。
- 项目生成图片。
- 项目分镜视频和最终视频。
- 工具输出中的图片与视频。
- AIGC 输出中的图片与视频。
- 具有安全可访问预览 URL 的公开媒体资产。

### 排除

- `type === "uploaded_image"` 的上传参考图片。
- `tool_asset_role === "input"` 的工具输入素材。
- `asset_role === "internal_base"` 或 `asset_role === "internal_layer"` 的内部中间资产。
- 音频、字幕、文本和无法识别为图片或视频的资产。

媒体归类优先使用明确资产类型，并以 MIME 类型补充工具与 AIGC 输出的图片/视频判断。所有卡片继续使用稳定的资产 ID 作为 React key。

## 视觉与交互

### 瀑布流

- 缩略图保持原始宽高比，不拉伸、不裁切。
- 使用 CSS columns 或等价的稳定 masonry 实现，不引入仅用于布局的重量级依赖。
- 卡片仅展示媒体、当前名称和简短时间信息，避免首页变成资产管理后台。
- Hover 时显示放大提示；触屏设备整张卡片均可点击。
- 视频卡片显示清晰的播放标识和时长（存在时）。

### 预览

- 图片使用 `object-contain` 在 Dialog 可用区域内完整显示。
- 视频使用原生播放器，保留控制条且不自动播放。
- Dialog 标题使用当前资产名称。
- 支持关闭按钮、`Escape` 和点击遮罩关闭。
- 预览中提供下载入口，并沿用现有资产命名规则。
- 关闭视频预览时停止播放，避免后台继续出声。

### 状态

- 加载态使用与瀑布流列宽一致的骨架占位，避免明显布局跳动。
- 当前分类为空时展示针对图片或视频的简洁空态。
- 查询失败时展示可理解的错误信息和重试入口。
- 搜索无结果时保留分类控件和搜索词，并提供清空搜索操作。

## 组件边界

- 首页服务端页面负责并行获取项目资产与工具/AIGC 资产，并将统一资产列表传给客户端画廊。
- 新的首页画廊客户端组件负责分类、搜索、排序、瀑布流与预览状态。
- 资产筛选和媒体归类提取为纯函数，复用现有 `asset-display` 安全 URL、名称和下载逻辑。
- 预览 Dialog 优先复用现有资产库交互模式，避免出现两套媒体预览行为。

## 数据流

1. 首页服务端并行请求现有资产列表接口。
2. 服务端失败时传递用户可理解的错误状态；成功时传递统一资产列表。
3. 客户端纯函数排除参考素材与内部资产，并归类为图片或视频。
4. 客户端按 `updated_at` 倒序排序，分类和关键词筛选在本地完成。
5. 用户点击卡片后，仅将选中资产写入预览状态，不重新请求资产列表。

## 可访问性

- 分类控件具备可识别的选中状态和键盘操作能力。
- 可点击卡片使用语义化按钮或等价键盘交互。
- 图片具有基于资产名称的替代文本。
- 视频播放标识不作为唯一的类型提示。
- Dialog 管理焦点，关闭后焦点返回触发卡片。
- 图标按钮提供 `aria-label` 和 tooltip。

## 测试与验收

- 单元测试覆盖公开生成媒体筛选、参考素材排除、内部资产排除、图片/视频归类和时间排序。
- 组件测试覆盖默认图片分类、分类切换、搜索、空态、错误态、图片预览、视频预览和关闭停止播放。
- 首页路由测试验证项目、工具和 AIGC 资产均被请求并聚合。
- 运行前端 Vitest、TypeScript、ESLint 和 production build。
- 使用 Playwright 在桌面、平板和手机视口验证瀑布流列数、原始比例、Dialog、无横向溢出和无控件重叠。

## 已批准决策

- 采用方案 A“聚焦切换”。
- 默认展示图片分类。
- 汇总所有来源的公开生成内容。
- 仅排除上传参考素材和内部中间资产。
- 按更新时间倒序展示。
- 图片与视频均在 Dialog 中放大预览。
