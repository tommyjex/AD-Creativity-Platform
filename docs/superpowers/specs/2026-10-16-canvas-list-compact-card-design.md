# 画布列表卡片信息精简

## 背景

画布列表卡片底部同时展示描述、节点与模型数量、更新时间和“打开画布”按钮，信息重复且占用较多纵向空间。卡片缩略图和标题已提供进入画布的入口，因此底部操作按钮没有必要保留。

## 目标

精简“我的画布”和“画布模板”共用的卡片内容，降低卡片高度，仅保留对列表扫描有价值的更新时间。

## 设计

- 删除卡片描述及“未填写说明”占位文本。
- 删除节点数和模型数。
- 删除底部“打开画布”“使用模板”和“查看模板”按钮。
- 在标题行下方仅保留更新时间，文案格式为“更新于 {格式化时间}”。
- 缩略图和标题继续作为主要打开入口，键盘焦点与禁用状态保持不变。
- 保留标题行中的运行状态、模板编辑、缩略图选择和删除操作。
- 不改变卡片封面比例、响应式列数、分页、筛选或后端接口。

## 交互边界

不将整个卡片改为单一点击区域，避免与编辑、选择缩略图和删除按钮产生嵌套交互。用户通过缩略图或标题进入画布或使用模板。

## 验证

- 组件测试确认描述、节点/模型统计和底部主按钮不再渲染。
- 组件测试确认更新时间仍显示，缩略图和标题仍可打开目标。
- 现有模板编辑、缩略图选择和删除操作测试继续通过。
- 使用 Playwright 检查桌面与移动端卡片高度、文本截断及操作按钮不重叠。
