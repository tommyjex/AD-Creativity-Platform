# 成片预览视口自适应设计

## 目标

剪辑完成后的结果预览在桌面端应尽量于一个视口内展示标题、操作区、完整视频和核心元信息，避免视频容器随内容列宽无限增高。

## 方案

- 项目详情“剪辑成片”标签页保持视频与元信息双栏。
- 视频以媒体自身宽高比渲染，并同时受可用视口高度与内容列宽约束。
- 桌面端预览最大高度按 `100dvh` 扣除顶部导航、标签栏、标题与操作区计算。
- 移动端不强制一屏容纳，保持自然纵向滚动和足够的可操作尺寸。
- 独立成片导出页复用相同的视频高度策略，避免两个预览入口体验不一致。
- 无预览地址时保留稳定的 16:9 空状态，不依赖媒体元数据。

## 验证

- 覆盖有视频、无视频 URL 和竖屏成片场景。
- 运行相关组件测试、项目工作台测试、TypeScript 与 ESLint。
- 在常见桌面和移动视口中检查视频完整显示、页面高度、双栏布局和控件重叠。
