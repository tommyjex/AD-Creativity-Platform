# 模态节点拖拽与图片操作图标优化设计

## 背景

文本、图片、视频和音频节点移除常驻标题后，节点主体仍整体使用 `nodrag`，导致原有标题拖拽区域消失后没有可靠的移动入口。图片节点右上角的精准编辑图标在当前画布比例下也偏大。

## 已确认方案

采用细粒度 `nodrag`：

- 四类模态节点允许从卡片内任意非交互区域直接拖动。
- 不增加可见标题、拖拽把手或顶部隐形热区。
- 仅按钮、输入框、图片预览按钮、音视频播放器及其控件继续阻止节点拖动。
- 节点端口、缩放控点和上下文菜单行为保持不变。

## 各模态拖拽边界

### 文本节点

- 文本内容区和空白区域可拖动节点。
- 复制按钮继续使用 `nodrag`，点击时不移动节点。
- 临时重命名输入框继续使用 `nodrag`，可正常选中和编辑文字。

### 图片节点

- 图片预览区域外围的卡片空间可拖动节点。
- 图片本身仍是“查看原图”按钮，保留 `nodrag`，点击时打开预览而不移动节点。
- 精准编辑按钮、分辨率角标和“已框选”状态保持原行为。

### 视频节点

- 视频播放器之外的节点空白、状态和信息区域可拖动。
- 视频元素、播放控制、全屏和音量等交互区域继续使用 `nodrag`、`nopan` 和 `nowheel`。

### 音频节点

- 音频播放器之外的节点空白、名称和信息区域可拖动。
- 音频元素及原生播放控件继续使用 `nodrag` 和 `nowheel`。

## 图片精准编辑图标

- 外置圆形容器由 `28px` 缩小为 `24px`。
- 按钮点击区域由 `24px` 缩小为 `20px`。
- `ScanSearch` 图标由 `14px` 缩小为 `12px`。
- 继续位于图片节点右上角外侧，右边缘与卡片对齐。
- 保留现有 `aria-label`、Tooltip、禁用态、层级和事件隔离。

为避免影响其他精准编辑入口，按钮组件通过明确的紧凑尺寸参数控制，默认尺寸保持不变。

- 后端接口和持久化契约

## 验收

- 文本、图片、视频和音频节点均能从非交互区域拖动并更新坐标。
- 点击复制、查看原图、精准编辑和播放器控件不会触发节点移动。
- 图片精准编辑按钮使用 `24px / 20px / 12px` 尺寸并保持右上外置。
- 桌面、平板和手机视口下按钮不遮挡节点、端口、连线或缩放控点。
- 相关 Vitest、完整 Vitest、TypeScript、ESLint 和三视口 Playwright 全部通过。
- 浏览器无新增控制台错误或页面异常。
