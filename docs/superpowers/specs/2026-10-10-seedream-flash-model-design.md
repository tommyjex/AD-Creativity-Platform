# Seedream Flash 可选模型设计

## 目标

为 AIGC 生图节点增加可选模型
`doubao-seedream-5-0-flash-260915`，同时保持
`doubao-seedream-5-0-pro-260628` 为默认模型，并保护只有 Pro 支持的图层拆分能力。

## 范围

本次改动覆盖 Pipeline 编辑器中的 Seedream 图片模型节点：

- 文生图
- 图生图
- 图像编辑
- 图层拆分

不修改独立图片生成接口的默认模型，不迁移已有节点，不改变图片尺寸规则、输入数量
和提示词优化协议。

## 模型能力

| 模型 | 文生图 | 图生图 | 图像编辑 | 图层拆分 |
| --- | --- | --- | --- | --- |
| `doubao-seedream-5-0-pro-260628` | 支持 | 支持 | 支持 | 支持 |
| `doubao-seedream-5-0-flash-260915` | 支持 | 支持 | 支持 | 不支持 |

新增集中式模型定义，包含稳定 ID、显示名称和支持的操作模式。前端选择器、模式切换
逻辑和校验均从该定义读取，避免散落字符串判断。后端保留独立的允许列表与能力校验，
不能信任前端提交值。

## 交互设计

生图节点配置面板新增“模型”选择器：

- 默认选中 `Seedream 5.0 Pro`。
- 可选 `Seedream 5.0 Flash`。
- 已有节点继续使用其保存的模型，不自动迁移。
- 文生图、图生图和图像编辑模式下均可切换 Pro/Flash。
- 进入图层拆分模式时，如果当前模型为 Flash，自动切换为 Pro。
- 图层拆分模式下 Flash 不出现在可选项中。
- 模型说明区域显示当前模型名称，取代固定的 “Seedream 5.0 Pro” 文案。

自动切换与现有操作模式更新在同一次节点配置写入中完成，避免产生短暂的无效草稿。

## 数据与执行

节点继续通过现有 `config.model` 字段持久化模型 ID，不增加数据库字段或迁移。

运行时流程：

1. 前端将所选模型写入节点配置。
2. 后端 schema 接受允许列表中的 Pro 或 Flash。
3. DAG 校验模型与操作模式能力；Flash + 图层拆分返回
   `model_not_supported_for_operation`。
4. AIGC Gateway 将节点保存的模型 ID 原样传给 Ark 图片生成请求。

未知模型 ID 必须在保存或运行校验阶段被拒绝，不能静默回退默认模型。

## 兼容性与错误处理

- 默认模型保持 Pro，现有模板和新建节点行为不变。
- 旧数据中的 Pro ID继续有效。
- Flash 节点切换到图层拆分时由前端自动恢复 Pro。
- 通过 API 构造的非法 Flash 图层拆分节点由后端明确拒绝。
- Ark 返回的模型权限、限流或生成错误沿用现有错误处理，不新增兜底重试。

## 测试

前端：

- 新建节点默认使用 Pro。
- 支持在适用模式下选择 Flash，并持久化完整模型 ID。
- Flash 节点切换到图层拆分时自动变为 Pro。
- 图层拆分模式不提供 Flash 选项。
- 模型说明显示当前选择。

后端：

- schema 接受 Pro 与 Flash，拒绝未知模型。
- DAG 接受 Flash 的文生图、图生图和图像编辑。
- DAG 拒绝 Flash 图层拆分。
- Gateway 将 Flash ID 传入 Ark 请求。
- 原有 Pro 图层拆分测试继续通过。

验证范围包括后端聚焦测试、前端相关 Vitest、前端 lint 和生产构建。
