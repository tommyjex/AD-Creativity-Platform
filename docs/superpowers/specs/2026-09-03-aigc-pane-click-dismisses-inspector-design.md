# AIGC 画布空白点击关闭详情栏设计

## 目标

点击 AIGC 画布空白区域时，退出当前节点上下文并关闭右侧详情栏，减少用户手动点击关闭按钮的操作。

## 交互契约

- 点击画布空白区域时：
  - 清除当前节点选择。
  - 关闭右侧详情栏。
- 无论详情栏当前位于“配置”“运行”还是“结果”标签，均执行相同行为。
- 关闭详情栏时保留当前标签和已选择的运行记录；用户之后通过顶部“详情”或节点点击重新打开时，沿用既有入口规则。
- 点击节点仍会选择该节点并打开“配置”标签。
- 点击节点内部控件、连接线、端口或详情栏内容不视为点击画布空白区域。
- 桌面停靠详情栏与窄屏右侧浮层使用同一行为。

## 实现边界

- 仅调整 `AigcEditorContent` 传给 React Flow 的 `onPaneClick` 回调。
- 面板状态继续使用现有本地 `openPanel`，不进入 Zustand store 或 Pipeline definition。
- 不改变自动保存、运行、节点删除、画布拖拽和缩放行为。

## 验证

- 单元测试分别覆盖“配置”“运行”“结果”标签下的空白点击。
- 单元测试确认空白点击后节点选择与详情栏同时清除。
- 单元测试确认再次点击节点仍打开“配置”标签。
- 浏览器验收覆盖桌面与窄屏详情栏关闭行为。
- 前端全量测试、类型检查、Lint 和生产构建通过。
