# 图片素材项目 AI 提示词与首次参考图设计

## 目标

在现有图片素材项目工作台中增加两项能力：

1. 使用 Seed Evolving 根据项目 Brief 生成可编辑的图片提示词建议。
2. 首次生成图片时允许上传一张参考图，并用 Seedream 5.0 Pro 进行参考图引导生成。

保持现有提示词版本、生成任务冻结、去重重试、TOS 归档和资产版本链不变。

## 交互方案

采用已确认的 A「紧凑同栏」布局：

- “AI 生成”按钮位于“图片提示词”标题右侧。
- 参考图上传区位于提示词编辑器下方、尺寸和格式参数上方。
- 上传区在无图片时显示拖拽/点击入口；有图片时显示缩略图、文件名、更换和移除操作。
- 首期仅支持一张参考图。
- AI 生成结果写入当前编辑器但不自动保存。编辑器存在未保存内容时，替换前显示确认。
- 只有用户点击“保存提示词”后才创建新的 `ImagePromptVersion`。

## AI 提示词生成

### 请求

新增项目级接口：

`POST /api/projects/{project_id}/image-prompts/generate`

请求体：

```json
{
  "current_prompt": "可选，当前编辑器内容"
}
```

后端读取项目当前 Brief，使用 `settings.ark_text_model`。当前默认模型为 `doubao-seed-evolving`。

模型输入包含：

- 商品名
- 卖点
- 目标受众
- 广告需求
- 图片用途（电商主图/海报）
- 目标平台
- 画面比例
- 视觉风格
- 目标语言
- 可选当前提示词，用于优化而非从零生成

### 输出

```json
{
  "prompt": "生成的图片提示词",
  "model": "doubao-seed-evolving"
}
```

要求：

- 中文项目输出中文提示词，英文项目输出英文提示词。
- 只输出可直接送入图片模型的提示词，不输出解释、Markdown 标题或代码块。
- 保留品牌名、商品名和 Brief 中的事实，不虚构规格或卖点。
- 明确主体、构图、背景、光线、材质、色彩、商业摄影/海报风格和画面比例。
- 画面卖点文案可不设置；适合画面表达时，从 Brief 卖点中择优选择最多 4 条，
  润色为简洁营销文案，但不得增加 Brief 未提供的事实。
- 每条需要显示在图片中的卖点文案必须使用 ASCII 英文双引号包裹，例如
  `"轻巧随行，随时鲜萃"`；提示词同时描述文字层级、位置、可读性、对比度
  和画面融合方式。
- 除双引号中的卖点文案外，不生成额外字幕、角标、价格、认证、CTA、Logo
  或其他画面文字。
- 中文项目生成中文文案，英文项目生成英文文案。
- 结果仍遵守现有中文 300 字、英文 600 词建议提示。

### 卖点文案校验与历史版本

- AI 输出和新保存的提示词允许包含 0–4 组成对、非空的 ASCII 双引号文案。
- 无引号表示不设置画面文字，是合法状态；空引号、未闭合引号、中文弯引号
  或超过 4 组文案不合规。
- 前端在编辑器中即时提示并禁用保存和生成；后端继续作为最终校验。
- 历史提示词版本不删除、不改写；无文字版本可继续生图，只有引号格式错误
  或超过 4 条的版本需要修正后保存新版本。
- 不新增数据库字段，完整图片提示词仍是卖点文案的唯一事实来源。

### 错误行为

- 请求期间按钮显示 loading 并禁用重复提交。
- 模型失败、超时或返回空文本时保留编辑器原内容。
- 后端返回统一脱敏错误；不创建提示词版本或图片任务。

## 首次生成参考图

### 上传

图片项目新增参考图上传接口，复用现有资产上传与 TOS 服务。

约束：

- 单张图片。
- 支持 PNG、JPEG、WebP。
- 使用现有上传大小限制和内容/MIME 校验。
- 资产属于当前图片项目，类型为上传图片，类别为参考素材，`asset_role=public`。
- 更换参考图只改变当前编辑器选择，不删除旧资产。

### 生成请求

扩展 `TextToImageGenerationRequest`：

```json
{
  "operation": "text_to_image",
  "prompt_version_id": "prompt-version-id",
  "reference_asset_id": "optional-reference-asset-id",
  "size": "1K",
  "format": "png"
}
```

无参考图时维持当前纯文生图行为。

有参考图时：

- 后端校验资产属于当前项目、状态成功、角色公开、MIME 为受支持图片。
- 生成任务冻结参考资产 ID、对象键/版本、创建时间、提示词版本和全部模型参数。
- 去重哈希包含参考资产快照。
- 后端签发参考图可访问 URL，并通过 Seedream 5.0 Pro `image` 输入提交。
- 业务 `operation` 仍为 `text_to_image`，metadata 额外记录：
  - `generation_mode=reference_guided`
  - `reference_asset_id`
  - `reference_image_count=1`
- 生成结果继续作为新的 public `generated_image` 资产保存。

参考图在任务提交后被更换或项目 Brief 被编辑，不改变已排队任务的冻结输入。失败重试复制原参考图快照；使用新参考图应创建普通新任务。

## 后端边界

### ModelArk

新增文本能力：

```python
generate_image_prompt(request) -> ImagePromptSuggestion
```

- Mock 适配器输出确定性的中英文建议。
- BytePlus 适配器使用 Responses/Chat 文本模型调用 `ark_text_model`。

扩展项目图片生成模型：

- 纯文生图不传 `image`。
- 参考图引导生成传单张 `image` URL。
- 不重新引入 Seedream 5.0 Pro 不支持的 `sequential_image_generation`。

### 安全与一致性

- 后端不信任客户端传入的参考图 URL，只接受资产 ID。
- 普通项目资产访问和软删除过滤规则继续生效。
- 参考资产不被 Brief stale 传播误标记；只有派生生成图片进入 stale 链。
- 数据库或 TOS 失败不产生成功图片资产。

## 前端组件

在 `ImageProjectWorkspace` 中增加：

- `GeneratePromptButton`
  - loading、错误、替换确认。
- `ImageReferencePicker`
  - 上传、缩略图、更换、移除。
  - 文件格式/大小前置校验。
- 生成按钮状态
  - 参考图上传中或 AI 提示词生成中时禁用。
  - 提示词必须先保存为版本，参考图选择无需创建提示词版本。

保持现有版本网格、整图编辑、图层编辑和资产库行为。

## 测试

### 后端

- Seed Evolving 请求包含完整 Brief 和目标语言。
- Mock/真实适配器只返回提示词文本。
- AI 失败不写提示词版本。
- 首次生成无参考图时保持原请求。
- 有参考图时 Seedream 请求携带单张图片 URL。
- 跨项目、stale、internal、非图片参考资产被拒绝。
- 任务冻结、去重、重试均包含参考资产快照。
- 派生资产 metadata 与来源关系正确。

### 前端

- AI 按钮 loading、成功写入、脏内容替换确认、失败保留。
- 单张参考图上传、更换、移除及非法文件错误。
- 首次生成请求正确携带或省略 `reference_asset_id`。
- 上传/AI 进行中禁用生成。
- 桌面和 390px 移动视口无横向溢出或控件重叠。

### 浏览器

- 使用真实 Seed Evolving 生成中文与英文提示词。
- 上传真实参考图并完成 Seedream 引导生成。
- 结果可预览、下载、设为当前并进入资产库。
- 控制台和网络无业务错误。

## 非目标

- 多参考图及参考图权重/顺序。
- AI 自动保存提示词版本。
- AI 流式写入编辑器。
- 参考图裁剪、抠图或预处理。
- 更改现有图片编辑和图层编辑规则。
