# AD Creativity Frontend

Next.js App Router frontend for the AD Creativity platform.

## Stack

- React 19
- Next.js 15 App Router
- TypeScript strict mode
- Tailwind CSS
- shadcn/ui style components

## Scripts

Install dependencies first:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Validate the project:

```bash
npm run typecheck
npm run lint
npm run build
```

`npm test` currently aliases `npm run typecheck`; focused component and API tests are planned for the later frontend validation task.
