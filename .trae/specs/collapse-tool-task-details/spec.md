# 工具任务卡片折叠详情 Spec

## Why

人物打码与全模态生视频任务卡片默认展示全部参数，列表信息密度过高，影响快速浏览任务 ID 和创建时间。需要将详细参数按需展开，并确保任务选择、展开和删除互不干扰。

## What Changes

- 人物打码与全模态生视频任务卡片默认仅展示任务 ID 和创建时间。
- 每张任务卡片增加独立展开按钮，允许同时展开多个任务。
- 点击任务主体只选择任务并驱动播放器，不改变展开状态。
- 点击展开按钮只展开或收起详情，不改变当前选中任务。
- 人物打码详情展示状态、输入视频、打码方式、打码强度和结果。
- 全模态生视频详情展示状态、模型、参考视频数量、结果和完整提示词。
- 失败任务的错误信息与重试入口显示在该任务展开详情中。
- 删除任务时同步清理其展开状态；分页切换不清空其他任务的展开状态。

## Impact

- Affected specs: 独立视频工具、全模态参考生视频任务列表与历史预览、全模态生视频任务列表分页与删除。
- Affected code: `frontend/components/workspace/tools-workspace.tsx`、`frontend/tests/tools-workspace.test.tsx`。
- 不涉及后端 API、数据库或任务数据结构。

## ADDED Requirements

### Requirement: 独立展开任务详情

系统 SHALL 为人物打码任务和全模态生视频任务提供独立的详情展开控制。

#### Scenario: 默认收起

- **WHEN** 任务列表首次渲染
- **THEN** 每张任务卡片只显示任务 ID、创建时间和操作按钮
- **AND** 状态与任务参数不显示

#### Scenario: 展开多个任务

- **WHEN** 用户分别点击多个任务的展开按钮
- **THEN** 每个任务独立保持展开状态
- **AND** 展开操作不改变当前选中任务

#### Scenario: 选择任务

- **WHEN** 用户点击任务主体
- **THEN** 系统选择该任务并更新关联播放器
- **AND** 该任务及其他任务的展开状态保持不变

#### Scenario: 删除已展开任务

- **WHEN** 用户删除一个已展开的全模态生视频任务
- **THEN** 系统同时移除该任务对应的展开状态
- **AND** 其他任务的展开状态保持不变

## MODIFIED Requirements

### Requirement: 人物打码任务详情

系统 SHALL 在展开区域显示任务状态、输入视频、打码方式、打码强度和结果；失败任务还显示错误信息和重试入口。

### Requirement: 全模态生视频任务详情

系统 SHALL 在展开区域显示任务状态、模型、参考视频数量、结果和完整提示词。

#### Scenario: 完整显示提示词

- **WHEN** 用户展开全模态生视频任务
- **THEN** 提示词按容器宽度自然换行
- **AND** 不使用单行截断、行数截断或省略号
