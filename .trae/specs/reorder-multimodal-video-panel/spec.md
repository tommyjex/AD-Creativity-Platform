# 全模态参考生视频面板重排与默认值调整 Spec

## Why

全模态参考生视频编辑页面当前把“创作提示词”放在最上方，参数选择行与参考素材上传行在其下方，导致用户先写提示词再回头配置参数，操作顺序不顺。同时时长默认 `4`、画幅默认 `16:9`，与“默认走自动时长、自动画幅”的常用意图不一致。本次调整让参数与参考素材前置，并把两项默认值改为自动。

## What Changes

- 将“参数选择行”（模型 / 分辨率 / 时长 / 画幅）与“参考素材上传行”（参考图 / 参考视频 / 参考音频）整体移动到“创作提示词”**上方**，顺序为：参数选择行 → 参考素材上传行 → 创作提示词。
- 时长输入默认值由 `4` 改为 `-1`（自动时长）。
- 画幅（aspect_ratio）默认值由 `16:9` 改为 `adaptive`（自适应）。
- 同步更新受影响的前端测试对默认值与结构的断言。

## Impact

- Affected specs: 全模态参考生视频配置扩展、独立视频工具模块。
- Affected code:
  - 前端：`frontend/components/workspace/tools-workspace.tsx`（`VideoGenerationPanel` 内的初始 state 默认值与 `CardContent` 内三块区域的渲染顺序）。
  - 前端测试：`frontend/tests/tools-workspace.test.tsx`（默认值断言与提交默认值相关用例）。
- 不涉及后端 schema、供应商适配层或接口变更；分辨率与时长的模型能力约束、校验逻辑均保持不变。

## MODIFIED Requirements

### Requirement: 全模态参考生视频配置

系统 SHALL 在“全模态参考生视频”面板中，将参数选择与参考素材上传置于创作提示词之上，并将时长与画幅的默认值设为自动。

#### Scenario: 面板区域顺序

- **WHEN** 用户打开全模态参考生视频编辑面板
- **THEN** 面板配置区自上而下依次为：参数选择行（模型、分辨率、时长、画幅）、参考素材上传行（参考图、参考视频、参考音频）、创作提示词
- **AND** 创作提示词位于两行配置之下

#### Scenario: 时长默认自动

- **WHEN** 用户打开面板且未修改时长
- **THEN** 时长输入框默认值为 `-1`
- **AND** 提交时在无修改的情况下 `duration_seconds` 为 `-1`（自动时长）
- **AND** 时长仍保留原有校验（`-1` 或模型允许范围内的正整数）

#### Scenario: 画幅默认自适应

- **WHEN** 用户打开面板且未修改画幅
- **THEN** 画幅选择器默认值为 `adaptive`（自适应）
- **AND** 提交时在无修改的情况下 `aspect_ratio` 为 `adaptive`
