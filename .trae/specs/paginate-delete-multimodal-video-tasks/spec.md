# 全模态生视频任务列表分页与删除 Spec

## Why

全模态参考生视频任务会持续累积，右侧“生成任务”列表当前一次展示全部历史记录，难以浏览和清理。需要限制单页任务数量，并允许用户安全删除不再需要的任务记录。

## What Changes

- 右侧“生成任务”列表按创建时间倒序分页，每页最多展示 10 条全模态参考生视频任务。
- 列表任务总数超过 10 条时显示上一页、页码与下一页控件；10 条及以下不显示分页控件。
- 每个全模态任务条目增加删除图标按钮，并在确认对话框确认后删除任务。
- 新增通用删除工具任务 API，仅删除工具任务记录，不删除关联输入、输出或工具资产。
- 新提交或重试创建的全模态任务会回到第一页并自动选中。
- 删除当前选中任务后，自动选中当前页第一条剩余任务；当前页无任务时返回上一有效页；没有剩余任务时清空选择并显示空状态。
- 删除请求失败时保留任务列表和选择状态，并显示用户可读错误反馈。
- 修复运行中后端未加载删除路由导致 `Method Not Allowed` 的问题，并验证实际服务契约与源码一致。
- 不改变视频生成、模型调用、参考素材、资产归档、结果预览、下载或任务重试语义。

## Impact

- Affected specs: 全模态参考生视频任务列表与历史预览、工具任务管理、工具资产管理。
- Affected code: `backend/app/api/routes.py`、`backend/app/repositories/base.py`、具体仓储实现及后端测试；`frontend/lib/api-client.ts`、`frontend/components/workspace/tools-workspace.tsx`、前端测试。
- **BREAKING**: 无。删除操作只移除任务记录，关联资产继续保留。

## ADDED Requirements

### Requirement: 全模态生视频任务分页

系统 SHALL 将右侧全模态生视频任务列表按创建时间倒序分页，每页最多展示 10 条任务。

#### Scenario: 多页浏览

- **WHEN** 全模态生视频任务总数超过 10 条
- **THEN** 当前页仅显示 10 条任务
- **AND** 列表显示上一页、当前页/总页数和下一页控件
- **AND** 用户可在有效页范围内切换页面

#### Scenario: 新任务出现

- **WHEN** 用户成功提交或重试全模态生视频任务
- **THEN** 列表回到第一页
- **AND** 新任务显示在第一页并自动选中

#### Scenario: 少量任务

- **WHEN** 全模态生视频任务总数不超过 10 条
- **THEN** 列表展示全部任务
- **AND** 不显示分页控件

### Requirement: 删除全模态生视频任务

系统 SHALL 允许用户从全模态生视频任务列表删除单个任务记录，并保护关联资产。

#### Scenario: 确认删除

- **WHEN** 用户点击任务的删除按钮并在确认对话框确认
- **THEN** 系统调用删除工具任务 API 并从列表移除该任务
- **AND** 不删除任务关联的参考图、参考视频、参考音频、生成结果或工具资产

#### Scenario: 取消删除

- **WHEN** 用户在确认对话框取消
- **THEN** 系统不调用删除 API
- **AND** 任务列表、当前页和当前选择保持不变

#### Scenario: 删除选中任务

- **WHEN** 用户删除当前选中任务
- **THEN** 系统选中当前页第一条剩余任务
- **AND** 当前页不再有任务时跳转至上一有效页并选中该页第一条任务
- **AND** 没有剩余任务时清空选择并显示空状态

#### Scenario: 删除失败

- **WHEN** 删除 API 返回错误
- **THEN** 系统保留任务列表、当前页和当前选择
- **AND** 显示用户可读错误反馈

## MODIFIED Requirements

### Requirement: 工具任务删除契约

系统 SHALL 支持按 ID 删除单个工具任务记录，且该操作不得级联删除关联资产。

#### Scenario: 运行时加载删除路由

- **WHEN** 后端服务以当前源码启动
- **THEN** 运行时 OpenAPI 在 `/api/tools/tasks/{task_id}` 路径声明 `DELETE` 方法
- **AND** 对不存在任务发起 `DELETE` 返回 404，而不是 405
- **AND** 前端确认删除时能够调用该运行时路由

#### Scenario: 删除后的查询

- **WHEN** 一个工具任务已被成功删除
- **THEN** 获取该任务的接口返回 404
- **AND** 工具任务列表不再返回该任务
- **AND** 关联资产仍可从工具资产和资产内容接口获取
