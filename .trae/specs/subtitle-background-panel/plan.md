# 字幕底板配置实施计划

目标：按用户已批准的三种背景策略修改代码，使用 MediaKit 基础文字背景色，保持预览、草稿、压制参数一致。

设计：复用每条字幕 style.background_color 的 RGBA 值，无需数据库迁移。null 为自动，透明值为关闭，非透明值为自定义。RGB 各通道均至少 245 时自动黑字无底板；各通道均至多 16 时白字无底板；其他或未知背景白字配 #333333B3。代表色无法证明区域均匀，允许手动覆盖。用户文字色始终优先。

步骤：

- [x] 修改后端自动配色和压制透明描边，保留颜色覆盖与低对比提示。
- [x] 添加前端一致的颜色解析与策略，配置自动/关闭/自定义、颜色、不透明度；预览底板贴合文字。
- [x] 回归测试白黑阈值、复杂与未知背景、手动覆盖、配置持久化和只读模式。
- [x] 执行后端测试、Ruff、编译、前端测试、lint、typecheck、git diff --check 和三视口 Playwright 检查。
- [x] 确认没有运行中的任务后重启本地后端，保留 16384 token 与 TLS-only 配置。

约束：不发起 Seed 或 MediaKit 计费调用，不修改真实工作区草稿，不提交 Git。此次实现沿用已讨论并批准的设计，当前会话内联执行。
