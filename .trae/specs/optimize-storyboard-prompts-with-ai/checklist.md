# Checklist

- [x] 分镜提示词编辑区域标题旁显示可访问的“AI 优化”按钮
- [x] 其他编辑操作进行中时 AI 优化按钮禁用，优化请求不可重复提交
- [x] AI 优化接口为同步 POST，并返回单一 `optimized_prompt`
- [x] 非空草稿作为主要优化输入，空白草稿回退到 `effective_video_prompt`
- [x] 优化上下文由后端读取项目 brief 和分镜权威数据，客户端不能伪造
- [x] 上下文包含当前分镜剧情、视觉提示、旁白、时长和画幅
- [x] 合并分镜上下文包含全部原子分镜及连续时间区间
- [x] 上下文按编辑器顺序包含参考图、参考视频、参考音频编号及首帧来源摘要
- [x] 上下文不包含 API Key、数据库凭据、签名 URL 或未选择资产内容
- [x] AI 优化保留人物、剧情事件、台词含义、商品信息和参考素材关系
- [x] AI 优化只增强镜头语言、动作连续性、镜头调度、节奏、转场和生成约束
- [x] 普通分镜优化结果保留唯一完整 `[0s-Ns]` 时间区间
- [x] 合并分镜优化结果保留全部原子区间、顺序和边界
- [x] 优化结果包含整体要求、连续时间轴、语音与字幕、负向约束章节
- [x] 有旁白时包含普通话语音和逐字同步简体中文字幕要求
- [x] 无旁白时不新增对白或字幕
- [x] 优化结果不超过 12000 字符
- [x] 非法 JSON、空、超长、缺少章节或时间轴错误的模型结果被拒绝
- [x] AI 优化成功只替换编辑框草稿，不自动保存数据库
- [x] 优化后 `savedPrompt` 保持不变，关闭弹窗触发现有未保存确认
- [x] AI 优化失败时原草稿保持不变并显示脱敏错误
- [x] 过期优化响应不会覆盖其他分镜或已关闭弹窗的草稿
- [x] 仅执行 AI 优化不会创建任务、触发视频生成或标记下游 stale
- [x] 后端测试覆盖普通分镜、合并分镜、空草稿、完整上下文和非法输出
- [x] 前端测试覆盖按钮、loading、草稿替换、未保存确认、失败和过期响应
- [x] `.venv` 后端全量测试通过
- [x] 前端 Vitest 与 TypeScript 类型检查通过
- [x] 本地 smoke test 完成“打开分镜提示词 -> AI 优化 -> 检查草稿 -> 保存提示词”
