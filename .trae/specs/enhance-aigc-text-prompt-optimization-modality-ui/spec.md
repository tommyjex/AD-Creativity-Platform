# 增强文本提示词优化与简化模态节点 UI Spec

## Why

当前文本节点的“优化提示词”仅面向生图场景，无法表达用户希望加强的方向，也不能根据具体下游 LLM、生图或生视频节点采用不同优化策略。统一模态节点同时持续显示“本地 / 上游”标签，并在上游模式下完全锁定文本，不符合用户对简洁界面和可编辑中继文本的需求。

## What Changes

- 将文本节点“优化提示词”改为弹窗流程，支持输入可选优化方向并选择一个直接连接的下游模型节点。
- 根据所选下游节点采用 LLM、生图或生视频专属提示词优化策略。
- 为上游文本增加当前节点级覆盖值；用户可编辑或优化上游文本，并可恢复当前界面所选 Run 的上游结果。
- 移除四类模态节点卡片和详情栏中可见的“本地 / 上游”标签及说明。
- 上游图片、视频、音频继续禁用上传和资产库选择；图片、视频节点标题栏不再显示下载按钮，下载仅保留在详情栏。
- 不修改上游节点、历史 Run、模型执行接口或媒体资产。
- **BREAKING**：旧版缺少明确目标节点的提示词优化请求不再默认按文生图处理，而是返回 `invalid_input`。

## Impact

- Affected specs: 提示词优化、统一模态节点、DAG 有效值、缓存 Hash、结果投影、媒体下载。
- Affected code: `backend/app/schemas/aigc.py`、`backend/app/services/modelark.py`、`backend/app/services/generation.py`、`backend/app/services/aigc_dag.py`、`backend/app/api/aigc_routes.py`、`frontend/lib/aigc/*`、`frontend/components/workspace/aigc/aigc-prompt-editor.tsx`、`aigc-editor.tsx`、`aigc-flow-node.tsx` 及相关测试。

## ADDED Requirements

### Requirement: 目标感知的提示词优化弹窗

系统 SHALL 在文本节点详情栏提供“优化提示词”操作。点击后打开弹窗，包含：

- 当前待优化文本的只读摘要；
- 可选“优化方向”多行输入，最多 2000 个 Unicode code point；
- “目标模型”选择器；
- 取消和“开始优化”操作。

目标选择器 SHALL 仅列出当前未保存 Pipeline definition 中，由该文本节点通过文本输出直接连接至 `prompt` 输入的以下模型节点：

- `llm`
- `text_to_image`
- `image_to_image`
- `video_generation`

候选项 SHALL 使用节点显示名称；存在多个同类型节点时逐项展示，不合并为类型选项。没有支持的直接下游时，入口 SHALL 禁用并提示先连接目标模型，不再默认按文生图优化。

#### Scenario: 选择多个直接下游中的一个

- **WHEN** 文本节点同时连接“LLM 节点 1”和“生视频节点 1”
- **THEN** 弹窗列出两个可选目标
- **AND** 用户只能为本次请求选择其中一个

#### Scenario: 间接下游不参与选择

- **WHEN** 文本节点先连接另一个文本节点，再由后者连接模型
- **THEN** 前一个文本节点不将该模型列为优化目标

#### Scenario: 下游连接在弹窗期间变化

- **WHEN** 所选目标被删除、断开或改变类型
- **THEN** 当前请求结果不得写回
- **AND** 用户收到目标已变化的提示

#### Scenario: 请求期间关闭弹窗

- **WHEN** 优化请求进行中
- **THEN** 取消按钮、关闭按钮和 Escape 关闭均禁用
- **AND** 页面卸载或文本节点被删除时即使响应到达也不得写回

### Requirement: 用户优化方向

优化方向 SHALL 是本次请求的可选临时输入，不写入节点配置、Pipeline、Run 或 Task。优化器 SHALL 将其视为偏好补充，不得用它覆盖原提示词中的明确硬约束。

后端 SHALL 分别从原文本及每条 BBox 引用说明中重新提取受保护字面量，不信任客户端提供的字面量列表。规范提取器按原字符串从左到右识别：

1. 现有 BBox 解析器可识别的完整结构化 token；
2. ASCII/中文配对引号 `"..."`、`“...”`、`「...」`、`『...』` 中的非空完整片段；
3. 单行反引号片段；
4. `http://` 或 `https://` 开头、终止于空白或配对关闭标点前的 URL；
5. 宽高比 `数字:数字`；
6. 带固定单位的有符号整数或小数，单位为 `%`、`px`、`K`、`s`、`秒`、`min`、`分钟`、`h`、`小时`、`帧`、`fps`、`度`、`°`。

重叠匹配选择起点相同的最长片段，仍相同时按上述类别优先级选择；结果保留原文大小写、标点、重复次数和出现顺序，不做 Unicode 或空白规范化。Provider 输出的对应字段必须以精确 code-point 子串形式包含每个字面量至少相同次数，否则整次响应失败。品牌、产品、颜色和否定语义等不能可靠依靠词法识别的约束，通过优化系统指令及固定回归语料验证。

#### Scenario: 未填写优化方向

- **WHEN** 用户不填写优化方向并开始优化
- **THEN** 系统仅根据当前文本和目标模型策略进行优化

#### Scenario: 优化方向与硬约束冲突

- **WHEN** 优化方向要求改变原文明确指定的品牌、产品、文字、数量、颜色、画幅、时长或否定条件
- **THEN** 优化结果保留原文硬约束
- **AND** 不执行冲突的优化方向

### Requirement: LLM 提示词优化策略

选择 `llm` 目标时，优化器 SHALL 参考 LLM 提示词工程原则，将提示词整理为与任务复杂度相匹配的结构：

- 明确角色、上下文、具体任务和约束；
- 对强模板任务明确步骤、输出格式与完成标准；
- 仅在原文已提供示例或用户明确要求时保留/组织示例，不凭空编造业务事实；
- 对复杂推理目标给出目标与约束，避免要求输出隐藏思维过程；
- 使用 Markdown 标题、列表或轻量 XML 划分规则、上下文和输入；
- 保持原语言、事实、变量、代码、URL 和硬约束。

优化结果 SHALL 只返回一个可直接作为下游 LLM 输入的提示词，不包含解释、评分、候选列表或 Markdown 代码围栏。

#### Scenario: 优化结构化任务

- **WHEN** 原提示词要求模型按固定字段生成广告分析
- **THEN** 优化结果明确任务、规则、输入边界和输出字段
- **AND** 不改变字段语义或添加不存在的业务数据

### Requirement: 生图提示词优化策略

选择 `text_to_image` 或 `image_to_image` 目标时，优化器 SHALL 参考 Seedream 提示词原则，并读取所选节点类型、操作模式、尺寸及其直接参考图数量：

- 文生图使用简洁自然语言明确主体、行为、环境、用途和必要美学元素；
- 待渲染文字使用双引号保留；
- 图片编辑明确编辑对象、动作和保持不变内容；
- 参考图生图明确每张参考图的对象、用途、保留特征和多图关系；
- 避免无意义形容词堆叠和模糊代词；
- 保持品牌、产品、文字、数量、颜色、画幅、否定条件与结构化 BBox 引用。

仅生图目标 SHALL 优化 BBox 引用说明。引用 ID、顺序、数量、坐标和安全 token 必须保持不变。

“安全 token”特指现有 BBox 模块根据引用 ID 生成并校验的结构化引用 token；用户仍不得手工输入坐标标签。BBox 顺序以文本节点 `bbox_references` 配置数组为准。图生图普通参考素材顺序以所选目标节点 `image` 输入端口在 definition `edges` 数组中的顺序为准。

API 中的 `reference_instructions` 与响应中的 `optimized_reference_instructions` 仅对应 BBox 引用说明，不对应普通参考图。二者按 `bbox_references` 数组索引一一映射，长度必须完全一致；普通参考图只通过数量和稳定顺序参与优化上下文。

#### Scenario: 图生图目标

- **WHEN** 用户选择有两张参考图的图生图节点
- **THEN** 优化结果明确两张图片各自的参考对象和用途
- **AND** 不交换、删除或新增参考关系

### Requirement: 生视频提示词优化策略

选择 `video_generation` 目标时，优化器 SHALL 参考 Seedance 提示词原则，并读取所选节点的生成模式、时长、画幅、是否生成音频及直接参考素材摘要：

- 用一句话概述主体、地点、事件、题材或风格；
- 按目标时长组织连续且合理的镜头或时间轴；
- 描述关键动作、表情、景别、机位、运镜、转场触发点；
- 按素材顺序明确图片、视频、音频的编号、用途和参考维度；
- 对编辑、首尾帧和多模态参考模式使用对应约束；
- 根据配置描述对白、环境音、音效、BGM 或无声要求；
- 保持原文事实、主体、台词、品牌、数量、时长和否定条件；
- 避免单位时间内无法完成的动作堆叠和不连续时间区间。

优化结果 SHALL 只返回一个可直接用于所选生视频节点的提示词，不包含解释、候选列表或代码围栏。

生视频参考素材摘要 SHALL 仅包含 `source_node_id`、`source_handle`、目标端口、媒体类型、角色和 1-based ordinal，不包含资产 URL 或媒体内容。角色由目标端口确定：`first_frame → first_frame`、`last_frame → last_frame`、`reference_images → reference_image`、`reference_videos → reference_video`、`reference_audios → reference_audio`。排序按目标端口语义固定为 `first_frame`、`last_frame`、`reference_images`、`reference_videos`、`reference_audios`；同一多值端口内按 definition `edges` 数组顺序编号。

#### Scenario: 带参考素材的生视频

- **WHEN** 所选节点连接了图片、视频和音频参考
- **THEN** 优化结果按实际输入顺序建立清晰素材映射
- **AND** 不引用不存在的素材编号

### Requirement: 上游文本覆盖

文本节点配置 SHALL 新增可空 `upstream_text_override`。有文本入边时：

- 无覆盖值时，有效文本为所选 Run 中的上游文本；
- 有覆盖值时，有效文本为覆盖值；
- 编辑上游文本或应用优化结果时创建/更新覆盖值；
- “恢复上游文本”清除覆盖值并立即显示当前界面所选 Run 的上游结果；
- 上游重新运行不得自动清除或替换覆盖值；
- 不得修改上游节点配置、上游 RunNode 或历史 Run snapshot。

断开入边时，节点继续使用原有本地 `text`；覆盖值保留但不生效，重新连接后再次生效，直到用户主动恢复上游文本。

`null` 唯一表示“没有覆盖”。空字符串或纯空白字符串表示用户明确创建的空覆盖，不得自动回退上游；当下游模型要求非空提示词时，由既有执行校验阻止运行。

覆盖值改变 SHALL 改变消费该文本的下游任务 `inputHash`。有覆盖值时仍保留原入边的拓扑依赖；上游失败、取消、超时或 unavailable 继续按既有规则阻塞该节点和后代，不将覆盖值作为失败回退。

#### Scenario: 编辑成功的上游文本

- **WHEN** 文本节点已有成功上游结果且用户修改内容
- **THEN** 当前节点保存覆盖值并将其作为有效文本
- **AND** 上游节点和历史结果不变
- **AND** 一次撤销可恢复编辑前状态

#### Scenario: 恢复上游

- **WHEN** 用户点击“恢复上游文本”
- **THEN** 覆盖值被清除
- **AND** 编辑器显示当前界面所选 Run 的上游文本

切换历史 Run 不修改覆盖值。只要覆盖值存在，所有 Run 视图都显示当前节点覆盖；清除覆盖后才显示当前界面所选 Run 对应的上游文本。

若所选 Run 的上游节点仍在等待、失败或 unavailable，清除覆盖后 SHALL 显示对应状态，不得显示其他 Run、本地文本或刚清除的覆盖值冒充上游文本。

#### Scenario: 优化上游文本

- **WHEN** 用户对上游有效文本执行优化
- **THEN** 优化结果写入 `upstream_text_override`
- **AND** 不写入本地 `text`

### Requirement: 优化请求一致性

优化请求 SHALL 捕获以下快照：

- 文本节点 ID、当前有效文本和覆盖状态；
- 当前界面所选 Run ID；本地模式时为 `null`；
- 优化方向；
- 所选目标节点 ID、类型及影响策略的配置；
- 生图 BBox 引用和参考数量，或生视频参考素材摘要。

文本、覆盖状态、所选 Run、引用、方向、目标节点、目标配置或相关连线在请求期间变化时，过期响应 SHALL 被丢弃。即使两个 Run 投影出相同文本，请求期间切换 Run 也必须使响应失效。优化成功 SHALL 作为一次 Store 历史操作应用且不自动保存 Pipeline；无变化结果不得新增历史记录或改变 dirty。

对生图目标，“无变化”比较范围为优化文本和全部引用说明；任一发生变化时二者 SHALL 作为一次原子 Store 更新提交。对 LLM、生视频目标，比较范围仅为优化文本，BBox 引用及说明不得参与写回。

#### Scenario: 重复提交

- **WHEN** 优化请求进行中
- **THEN** 弹窗输入、目标选择和提交按钮禁用
- **AND** 不允许第二个并发请求

#### Scenario: 服务失败

- **WHEN** Provider、解析或输出校验失败
- **THEN** 原文本和引用保持不变
- **AND** 弹窗显示脱敏错误并允许重试

### Requirement: 统一优化 API 契约

现有 `POST /api/aigc/prompts/optimize` SHALL 扩展为统一目标感知契约，至少包含：

- `target_node_id`
- `target_type`
- 目标类型所需的白名单配置摘要
- `optimization_direction`
- `text`
- 生图引用说明或生视频参考素材摘要

目标配置摘要 SHALL 采用按 `target_type` 区分的白名单结构，只传影响优化策略的字段：

- `llm`：模型标识和当前 `system_prompt`；
- `text_to_image / image_to_image`：模型、操作模式、尺寸、参考图数量；
- `video_generation`：模型、生成模式、任务类型、时长、画幅、是否生成音频及参考素材摘要。

响应 SHALL 固定包含：

- `optimized_text: string`
- `optimized_reference_instructions: string[]`

生图目标的引用说明数组长度和顺序必须与请求一致；LLM、生视频目标必须返回空数组。前端只有在整个响应通过校验后才执行原子写回。

后端 SHALL 对目标类型、长度、配置组合、引用数量和输出结构进行权威校验。接口不得保存 Pipeline、创建 Run/Task 或调用图片/视频生成接口。

#### Scenario: 非法目标

- **WHEN** 请求指定不支持的目标类型或与目标类型不匹配的配置
- **THEN** API 返回 `invalid_input`
- **AND** 不调用优化 Provider

#### Scenario: 旧版无目标请求

- **WHEN** 请求缺少 `target_node_id`、`target_type` 或目标配置摘要
- **THEN** API 返回 `invalid_input`
- **AND** 不再隐式转换为文生图优化

## MODIFIED Requirements

### Requirement: 模态节点来源展示

文本、图片、视频和音频节点的卡片及详情栏 SHALL 不显示可见的“本地”“上游”“当前使用本地内容”“已连接上游”等来源标签或说明。系统仍 SHALL 根据入边派生来源模式，并为状态、可访问名称和业务逻辑保留非视觉语义。

#### Scenario: 本地模态节点

- **WHEN** 模态节点没有入边
- **THEN** 详情栏直接展示可编辑文本或媒体选择控件
- **AND** 不显示“本地”标签

#### Scenario: 上游模态节点

- **WHEN** 模态节点存在入边
- **THEN** 详情栏直接展示有效结果或必要的等待/失败状态
- **AND** 不显示“上游”标签

### Requirement: 上游媒体编辑限制

图片、视频和音频节点存在入边时 SHALL 禁用本地上传和从资产库选择；图片精准框选等本地资产编辑继续禁用。相关本地备用资产保留在配置和资产保护关系中，断开入边后恢复。

#### Scenario: 上游媒体详情

- **WHEN** 用户打开有上游入边的图片、视频或音频节点详情
- **THEN** 上传按钮和资产库选择入口不可操作
- **AND** 当前上游媒体仍可预览或播放

### Requirement: 图片与视频下载位置

图片和视频模态节点标题栏 SHALL 不再显示下载按钮。可用图片和视频的下载操作 SHALL 仅出现在详情栏；等待、失败、不安全 URL 或 unavailable 时不显示或禁用下载。

“unavailable”指资产投影的 `available=false`。“不安全 URL”沿用现有下载模块的受控 URL 判定；本次变更不得放宽允许的协议、主机或同源规则。

音频节点的现有标题栏与详情栏下载行为不在本次修改范围内。

#### Scenario: 可用上游图片

- **WHEN** 上游图片结果可用
- **THEN** 节点标题栏没有下载按钮
- **AND** 详情栏提供下载图片操作

#### Scenario: 可用上游视频

- **WHEN** 上游视频结果可用
- **THEN** 节点标题栏没有下载按钮
- **AND** 详情栏提供下载视频操作

### Requirement: 模态节点运行语义

除文本覆盖值外，统一模态节点的拓扑、RunNode、无 Task Attempt、资产透传、失败传播、缓存、模板净化和历史 Run 语义保持不变。文本覆盖值只改变当前文本节点的有效文本与下游 Hash，不改变上游依赖关系。

## REMOVED Requirements

### Requirement: 无图片下游时默认文生图优化

**Reason**: 优化必须绑定用户明确选择的直接下游模型，避免采用错误策略。

**Migration**: 没有受支持直接下游时禁用优化入口，并提示连接 LLM、生图或生视频模型。

### Requirement: 上游文本只读

**Reason**: 文本中继需要允许在当前节点进行人工修订和目标感知优化。

**Migration**: 原本地 `text` 保持不变，已有节点默认 `upstream_text_override=null`；新增覆盖字段承载上游文本编辑结果。

### Requirement: 模态节点显示来源标签

**Reason**: 来源已能通过连接关系、控件状态和结果状态表达，重复标签增加界面噪音。

**Migration**: 移除可见标签，不移除内部 `local / upstream` 派生逻辑。
