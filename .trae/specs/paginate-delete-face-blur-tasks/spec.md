# 人物打码任务列表分页与删除 Spec

## Why

人物打码任务列表会持续累积，当前一次渲染全部任务，难以定位和操作历史记录；同时用户无法移除不再需要的任务记录。需要提供固定页容量和安全的任务删除能力。

## What Changes

- 人物打码任务列表按创建时间倒序分页展示，每页最多 10 条任务。
- 列表底部增加上一页、页码和下一页控件；任务总数不超过 10 时不显示分页控件。
- 每个任务条目提供删除图标按钮，并在确认对话框确认后删除任务。
- 新增删除工具任务 API，仅删除任务记录，不删除任务关联的输入、输出或工具资产。
- 删除已选中任务后，自动选中当前页第一条可用任务；当前页无任务时，返回上一有效页；无剩余任务时清空选择并显示空状态。
- 删除失败时保留当前列表和选择状态，并展示用户可读错误反馈。
- 不改变人物打码的提交、轮询、视频对比、资产库或任务重试行为。

## Impact

- Affected specs: 独立视频工具、工具任务管理、工具资产管理。
- Affected code: `backend/app/api/routes.py`、`backend/app/repositories/base.py`、具体仓储实现及后端测试；`frontend/lib/api-client.ts`、`frontend/components/workspace/tools-workspace.tsx`、前端测试。
- **BREAKING**: 无。删除操作仅影响任务记录，关联资产继续保留。

## ADDED Requirements

### Requirement: 人物打码任务分页

系统 SHALL 将人物打码任务列表按创建时间倒序分页，每页最多展示 10 条。

#### Scenario: 多页浏览

- **WHEN** 人物打码任务总数超过 10 条
- **THEN** 当前页仅显示 10 条任务
- **AND** 列表显示上一页、当前页/总页数和下一页控件
- **AND** 用户可在有效页范围内切换页面

#### Scenario: 新任务出现

- **WHEN** 用户成功提交新的人物打码任务
- **THEN** 列表回到第一页
- **AND** 新任务显示在第一页并自动选中

#### Scenario: 少量任务

- **WHEN** 人物打码任务总数不超过 10 条
- **THEN** 列表展示全部任务
- **AND** 不显示分页控件

### Requirement: 删除人物打码任务

系统 SHALL 允许用户从人物打码任务列表删除单个任务记录，并保护关联资产。

#### Scenario: 确认删除

- **WHEN** 用户点击某个人物打码任务的删除按钮并在确认对话框确认
- **THEN** 系统调用删除工具任务 API 并从列表移除该任务
- **AND** 不删除该任务关联的输入、输出和工具资产

#### Scenario: 删除选中任务

- **WHEN** 用户删除当前选中任务
- **THEN** 系统选中当前页第一条剩余任务
- **AND** 当前页不再有任务时跳转至上一有效页并选中该页第一条任务
- **AND** 没有剩余任务时清空选择并显示空状态

#### Scenario: 取消删除

- **WHEN** 用户在确认对话框取消
- **THEN** 系统不调用删除 API
- **AND** 任务列表和当前选择保持不变

#### Scenario: 删除请求失败

- **WHEN** 删除 API 返回错误
- **THEN** 系统保留任务列表和当前选择
- **AND** 显示用户可读错误反馈

## MODIFIED Requirements

### Requirement: 工具任务列表

系统 SHALL 支持删除单个工具任务记录，且删除的任务 ID 后续不可再通过任务查询接口获取。

#### Scenario: 删除后的查询

- **WHEN** 一个工具任务已被成功删除
- **THEN** 获取该任务的接口返回 404
- **AND** 任务列表不再返回该任务
