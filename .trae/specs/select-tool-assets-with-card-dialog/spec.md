# 全模态参考素材工具资产卡片选择 Spec

## Why

全模态参考生视频卡片页目前通过下拉菜单选择参考图、参考视频和参考音频，资产较多时不便浏览，也无法直观看到缩略图、资产名称和来源信息。用户需要从“工具资产”中以弹窗卡片方式选择参考素材，确认后再加入当前配置。

## What Changes

- 将全模态参考生视频卡片页中参考图、参考视频、参考音频的“从资产库选择”入口从下拉菜单改为弹窗卡片选择器。
- 弹窗仅展示对应模态的“工具资产”，即 `project_id` 为 `NULL` 且属于工具资产池的资产；不展示项目资产。
- 每个资产卡片展示缩略图或类型占位、资产名称、素材类型、创建时间或来源信息，便于用户识别。
- 弹窗支持多选，用户点击“确认选择”后才把所选资产加入当前参考素材列表。
- 已选素材仍展示在对应输入区域下方，并继续支持逐项移除；移除仅删除当前配置引用，不删除资产本体。
- 保留本地上传能力，上传后的工具资产仍自动加入当前参考素材列表。
- 后端接口若已能返回工具资产，则优先复用现有 `/api/tools/assets` 与前端资产状态；仅在发现工具资产被过滤或缺少访问 URL 时补齐最小后端修正。

## Impact

- Affected specs: 全模态参考素材管理、工具资产池、全模态参考生视频工作台。
- Affected code: `frontend/components/workspace/tools-workspace.tsx`、`frontend/tests/tools-workspace.test.tsx`；必要时涉及 `frontend/lib/api-client.ts`、`backend/app/api/routes.py`、资产列表相关后端测试。

## MODIFIED Requirements

### Requirement: 全模态参考素材管理

系统 SHALL 在全模态参考生视频卡片页为参考图、参考视频、参考音频提供从工具资产池选择素材的弹窗卡片交互，并继续支持上传与移除当前引用。

#### Scenario: 打开工具资产选择弹窗

- **WHEN** 用户点击参考图、参考视频或参考音频区域的“从工具资产选择”入口
- **THEN** 系统打开对应模态的资产选择弹窗
- **AND** 弹窗仅展示 MIME 类型兼容且属于工具资产池的资产
- **AND** 参考图仅展示图片工具资产，参考视频仅展示视频工具资产，参考音频仅展示音频工具资产
- **AND** 项目资产不得出现在该弹窗中

#### Scenario: 以卡片浏览工具资产

- **WHEN** 弹窗展示可选工具资产
- **THEN** 每个资产以卡片形式展示
- **AND** 图片资产显示图片缩略图
- **AND** 视频资产显示视频缩略图或可识别的视频占位
- **AND** 音频资产显示可识别的音频占位
- **AND** 卡片显示资产名称、素材类型以及可用的创建时间或来源信息

#### Scenario: 确认选择工具资产

- **WHEN** 用户在弹窗中选择一个或多个工具资产并点击“确认选择”
- **THEN** 系统将所选资产追加到对应模态的已选参考素材列表
- **AND** 已存在的资产 ID 不重复加入
- **AND** 弹窗关闭后，已选素材列表与提交请求保持同步

#### Scenario: 取消选择

- **WHEN** 用户在弹窗中选择资产后点击取消或关闭弹窗
- **THEN** 系统不修改当前已选参考素材列表

#### Scenario: 无可选工具资产

- **WHEN** 对应模态没有可选工具资产
- **THEN** 弹窗展示空状态
- **AND** 用户仍可通过本地上传添加素材

#### Scenario: 移除已选工具资产引用

- **WHEN** 用户在当前已选参考素材列表中移除某个资产
- **THEN** 系统仅移除当前配置中的引用
- **AND** 不删除资产本体、对象存储文件或其他任务引用
