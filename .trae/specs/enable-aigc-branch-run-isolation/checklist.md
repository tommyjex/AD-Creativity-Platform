# 验收清单

- [x] 局部 Run 冲突范围等于起始节点及其全部有向下游节点
- [x] 局部 Run 投影范围等于冲突范围及其全部必要上游依赖
- [x] `full` Run 的冲突范围和投影范围均覆盖整张画布
- [x] 非法或缺失 `start_node_id` 不会退化为全画布范围
- [x] 范围计算失败会明确报错，不回退无向连通图
- [x] 共享上游、下游范围不相交的两个分支可同时 queued/running
- [x] 共享上游无缓存时允许两个 Run 独立计算上游
- [x] 并行 Run 不共享进行中的任务、结果或资产
- [x] 同一分支或下游范围相交的 Run 仍返回活动冲突
- [x] 从共同上游启动的 Run 与其所有下游分支冲突
- [x] `full` Run 与任一局部分支 Run 双向冲突
- [x] Memory 与 MySQL Repository 的冲突和幂等语义一致
- [x] Repository 冲突检查在原有原子事务或锁区间内完成
- [x] 同一分支的真实并发提交只有一个成功创建 Run
- [x] 文生图分支 A 成功后，分支 B 启动不会清空 A 的图片
- [x] 分支 B 成功后，A、B 分别显示自身最近结果
- [x] 分支 C 失败或取消不会影响 A、B 的结果和操作
- [x] 每个节点按投影范围选择最新相关 Run
- [x] 前端同时加载不同分支所需的多个历史 Run 详情
- [x] 多个活动 Run 独立轮询，并在各自进入终态后停止
- [x] 单个 Run 详情加载失败不清空其他分支状态和结果
- [x] 详情加载前或失败时仍从 Run summary 计算投影范围
- [x] 选择某分支历史 Run 不覆盖兄弟分支状态或结果
- [x] 共享上游节点可投影最新相关活动 Run
- [x] 不同分支的 pending 创建请求可以并行
- [x] pending 范围相交时前端阻止重复提交
- [x] 任一活动或 pending Run 存在时顶部执行全部保持禁用
- [x] 局部预检只检查当前分支及必要依赖
- [x] 兄弟分支配置无效不阻止有效分支局部运行
- [x] 全画布基础图结构错误仍阻止局部运行
- [x] `full` Run 仍校验整张画布
- [x] 历史 Run 无需数据库迁移即可采用新范围语义
- [x] 后端范围、Repository、Executor 回归测试通过
- [x] 前端 Run scope、编辑器和节点组件测试通过
- [x] 后端完整测试通过
- [x] 前端完整 Vitest、TypeScript、ESLint 和 production build 通过
- [x] Playwright 使用 Mock 网关，不触发真实计费接口
- [x] Playwright 在 1440x1000、1024x768、390x844 视口通过
- [x] Playwright 无页面异常、控制台错误、横向溢出或控件重叠
