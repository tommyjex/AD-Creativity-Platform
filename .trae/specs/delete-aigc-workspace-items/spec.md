# AIGC 工作台条目删除规格

## 背景

AIGC 工作台的“画布模板”和“我的画布”列表目前缺少条目级删除能力，用户无法清理不再需要的模板或从未运行的画布。删除行为需要同时保护历史运行数据，并明确模板与由模板创建的画布之间的独立关系。

## 变更范围

- 在“画布模板”和“我的画布”的每个条目上提供删除图标。
- 点击删除图标后使用应用内确认弹窗，不使用浏览器原生确认框。
- 新增模板与 Pipeline 删除 API；成功返回 `204 No Content`，目标不存在返回 `404 Not Found`。
- 删除成功后重新获取并刷新用户当前所在的模板或画布列表。
- 删除失败时保留当前条目和列表状态，并展示可理解的错误反馈。
- Pipeline 无历史 Run 时物理删除；仅有终态历史 Run 时软删除并从工作台隐藏；存在 queued/running Run 时返回 `409 Conflict`。任何路径均不得级联删除历史 Run、RunNode、Task、任务资产关联或结果资产。
- 删除模板不删除、不修改由该模板创建的既有画布；既有画布的定义、运行和后续编辑能力保持不变。

## 影响范围

- 后端：AIGC Repository Protocol、Memory/MySQL 仓储、删除服务与 API 路由。
- 前端：AIGC API client、模板/画布列表查询、条目操作和应用内确认弹窗。
- 测试：Memory/MySQL 仓储契约、API、前端组件、全量回归和浏览器验收。
- 不改变画布创建、模板实例化、画布编辑、保存、执行、重试和资产删除语义。

## 新增需求

### 需求：删除画布模板

系统必须允许用户删除单个画布模板，同时保持既有画布实例独立可用。

#### 场景：确认删除模板

- **当** 用户点击模板条目的删除图标
- **则** 系统打开应用内确认弹窗，明确展示待删除模板及操作后果
- **并且** 用户确认后调用模板删除 API
- **并且** 删除成功返回 `204 No Content`
- **并且** 前端刷新当前模板列表，已删除模板不再出现

#### 场景：取消删除模板

- **当** 用户在确认弹窗中取消或关闭弹窗
- **则** 系统不调用删除 API
- **并且** 当前模板列表、筛选条件和分页状态保持不变

#### 场景：删除模板不影响既有画布

- **给定** 一个或多个 Pipeline 已由该模板创建
- **当** 用户删除该模板
- **则** 模板记录被删除
- **并且** 既有 Pipeline 及其定义、历史 Run、任务和资产保持不变
- **并且** 既有 Pipeline 仍可打开、编辑、保存和运行

### 需求：删除我的画布

系统必须允许用户删除从未产生 Run 的 Pipeline，并归档仅含终态历史 Run 的 Pipeline，同时保护所有历史运行数据。

#### 场景：删除无历史 Run 的画布

- **给定** Pipeline 从未产生任何 Run
- **当** 用户在画布条目上点击删除图标并在应用内确认弹窗中确认
- **则** 系统调用 Pipeline 删除 API
- **并且** 删除成功返回 `204 No Content`
- **并且** 前端刷新当前画布列表，已删除画布不再出现

#### 场景：仅存在终态历史 Run

- **给定** Pipeline 至少存在一个 Run，且所有 Run 均为 succeeded、failed 或 canceled 等终态
- **当** 用户确认删除该 Pipeline
- **则** API 返回 `204 No Content`
- **并且** Pipeline 被标记为软删除，不再出现在列表或普通详情接口
- **并且** Run、RunNode、Task、任务资产关联和结果资产均不得被删除或修改
- **并且** 系统不得通过级联删除绕过该保护
- **并且** 前端刷新列表并移除该画布条目

#### 场景：存在活动 Run

- **给定** Pipeline 存在 queued 或 running Run
- **当** 用户确认删除该 Pipeline
- **则** API 返回 `409 Conflict`
- **并且** Pipeline 和活动 Run 保持可见且不被修改

### 需求：删除 API 契约

系统必须为模板和 Pipeline 提供一致、幂等边界清晰的删除接口。

#### 场景：删除接口

- **当** 客户端删除模板
- **则** 使用 `DELETE /api/aigc/templates/{template_id}`
- **当** 客户端删除 Pipeline
- **则** 使用 `DELETE /api/aigc/pipelines/{pipeline_id}`
- **并且** 删除成功统一返回 `204 No Content` 且响应体为空

#### 场景：目标不存在

- **当** 删除接口收到不存在的模板 ID 或 Pipeline ID
- **则** API 返回 `404 Not Found`
- **并且** 不修改其他模板、Pipeline、运行或资产数据

#### 场景：删除失败

- **当** 删除请求因 `404`、`409`、网络错误或服务端错误失败
- **则** 前端不得乐观移除条目
- **并且** 当前视图、筛选条件、分页状态和列表内容保持不变
- **并且** 前端展示对应的用户可读错误反馈

### 需求：条目级删除交互

系统必须在模板和画布条目上提供独立、可访问且不会误触条目主操作的删除入口。

#### 场景：点击删除图标

- **当** 用户点击条目级删除图标
- **则** 不触发模板实例化、模板编辑或打开画布等卡片主操作
- **并且** 应用内确认弹窗展示正确的条目名称与类型
- **并且** 确认期间防止重复提交

#### 场景：删除后刷新当前列表

- **当** 删除 API 返回 `204 No Content`
- **则** 前端使当前视图对应的列表查询失效并重新获取数据
- **并且** 保持用户当前所在的“画布模板”或“我的画布”视图
- **并且** 使用服务端最新结果处理当前页因删除产生的条目变化
