# AIGC 多轨剪辑字体选择增量 Spec

## 1. 背景

多轨剪辑节点已经支持文字与 SRT 字幕元素的字号、颜色、背景色和基础字形样式，但不能选择 MediaKit 字体。MediaKit 官方多轨剪辑契约使用元素顶层字段 `font_type`，该字段支持预置字体 ID，也支持公网可访问的 TTF/OTF 字体 URL。

本增量为文字轨道和字幕轨道提供统一字体配置，同时保持既有草稿和 Provider 请求兼容。

## 2. 目标

- 文字元素和字幕元素均可选择 MediaKit 官方预置字体。
- 文字元素和字幕元素均可输入公网 HTTPS TTF/OTF 字体 URL。
- 自定义字体可加载时在画面预览中显示；加载失败时明确提示并回退系统字体。
- 保存后的字体配置可通过后端校验、持久化并准确映射到 MediaKit `font_type`。
- 未配置字体的历史草稿继续使用 MediaKit 默认字体。

## 3. 非目标

- 不上传、托管或转存字体文件。
- 不代理下载字体，不在后端探测字体 URL 内容。
- 不提供字体授权或版权担保。
- 不模拟 MediaKit 预置字体的本地字形。
- 不改变 SRT 内容、字幕时间轴或现有文字排版能力。

## 5. 数据模型

前后端共享的 `MultiTrackTextStyle` 增加：

```text
font_type: string | null
```

- 默认值为 `null`。
- `null` 表示不向 MediaKit 发送 `font_type`，沿用 Provider 默认字体。
- 预置模式保存对应字体 ID。
- 自定义模式保存完整 HTTPS TTF/OTF URL。
- 文字和字幕继续共用同一套样式结构。

定义迁移、清洗白名单、序列化和草稿恢复必须保留该字段。旧配置缺失字段时按 `null` 处理，不提升 Definition 版本。

## 6. 属性检查器

在文字与字幕共用的“文字样式”区域增加字体控件：

1. 使用分段控件切换“预置字体”和“自定义 URL”。
2. 预置模式使用下拉菜单，包含默认字体及第 4 节全部官方字体。
3. 自定义模式显示单行 URL 输入框。
4. 切换到预置模式后，选择项立即写入 `style.font_type`。
5. 切换到自定义模式后，只有非空输入才写入配置；清空输入恢复 `null`。
6. 无效 URL 在字段下方显示错误，并进入现有执行前校验；不得静默改写为其他字体。

## 7. 校验

`font_type` 满足以下任一条件时有效：

- 为 `null`；
- 为第 4 节列出的官方预置字体 ID；
- 为绝对 HTTPS URL，URL 路径以 `.ttf` 或 `.otf` 结尾，匹配时忽略大小写并允许查询参数和片段。

URL 不允许用户名或密码。长度上限为 2048 字符。校验仅检查结构，不发起网络请求。非法值产生稳定的 `invalid_font_type` 问题，阻止保存或执行。

## 8. 预览

- 对自定义字体 URL，前端使用浏览器 `FontFace` API 加载，并按 URL 缓存加载结果。
- 加载成功后，当前可见的文字元素使用该字体族。
- 加载中使用系统字体，不阻断编辑。
- 加载失败时继续使用系统字体，并在字体控件附近显示“浏览器无法加载字体，MediaKit 合成仍会尝试使用该 URL”。
- 对 MediaKit 预置字体 ID，不伪造近似字体；预览继续使用系统字体，并显示“最终字形以 MediaKit 合成为准”。
- 字体加载失败不修改 `font_type`，也不阻止保存或执行；只有 URL 结构非法才属于校验错误。

SRT 字幕文件内容当前不在画面预览中解析，本次只保证字幕元素的字体配置、持久化和 Provider 映射。文字元素继续支持实时字形预览。

## 9. Provider 映射

内部配置继续把字体保存在 `style.font_type`。构建 MediaKit 元素时：

- `style.font_type` 非空时，将其复制为元素顶层 `font_type`。
- `style.font_type` 为空时，不发送该字段。
- 内部 `style.font_type` 不作为嵌套字段重复发送。
- 文字和字幕使用完全相同的映射规则。

不得记录自定义字体 URL 的完整值；诊断日志只可记录字体来源类型（默认、预置、自定义）及脱敏主机信息。

## 10. 错误处理

- 非法字体 ID 或 URL：前后端均返回 `invalid_font_type`。
- 浏览器字体加载失败：软失败，显示提示并回退系统字体。
- MediaKit 拒绝字体：沿用现有 `provider_rejected` 或 `provider_failed` 错误链路。
- 历史草稿缺少 `font_type`：自动按 `null` 读取，不报错。

## 11. 验收标准

- 文字和字幕属性检查器均显示字体模式和对应输入控件。
- 10 个官方预置字体可选，保存后 ID 不变。
- 示例 URL `https://xujianhua-utils.tos-cn-beijing.volces.com/ECOVACS/centurygothic.ttf` 可保存并映射到 Provider。
- 自定义 `.otf` URL 及带查询参数的 URL 可通过校验。
- HTTP、相对 URL、含认证信息、非 TTF/OTF URL 和超长值被拒绝。
- 自定义字体成功加载时文字预览使用独立字体族。
- 字体加载失败时出现提示且仍可保存和执行。
- MediaKit 请求中，文字和字幕元素的 `font_type` 位于元素顶层。
- 未配置字体时 Provider 请求不包含 `font_type`。
- 旧草稿加载、保存和执行行为保持兼容。
- 前后端单元测试、类型检查、Lint 和生产构建通过。
- Playwright 在桌面、平板和移动端验证字体选择、自定义 URL、保存恢复及无真实 Provider 请求。
