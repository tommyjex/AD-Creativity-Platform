# 全模态参考生视频配置扩展 Spec

## Why

全模态参考生视频当前仅支持固定的 4、8、12 秒时长，且参考素材选择仅限工具页已加载的资产。用户需要按模型能力输入任意合法整秒时长，并在同一配置中管理上传或从资产库选择的图片、视频和音频参考素材。

## What Changes

- 将全模态参考生视频时长控件改为整秒数值输入，并根据所选模型执行前后端一致的范围校验。
- `Seedance 2.0`、`Seedance 2.0 Fast` 与 `Seedance 2.0 Mini` 支持 4 至 15 秒；`Seedance 2.5` 支持 4 至 30 秒。
- 时长支持特殊值 `-1`，表示由 Seedance 自动确定生成时长；该值适用于全部支持的模型。
- 参考图片、视频和音频均支持本地上传、从资产库选择，以及提交前移除当前引用。
- 资产库选择器显示当前用户可用的兼容公共资产；移除引用不删除资产或对象存储文件。

## Impact

- Affected specs: 独立视频工具模块、工具素材管理、Seedance 视频生成适配层。
- Affected code: 工具生视频请求 schema、ModelArk 请求映射、工具视频生成路由、工具工作台、资产选择器、API 类型、后端与前端测试。

## MODIFIED Requirements

### Requirement: 全模态参考生视频配置

系统 SHALL 在“全模态参考生视频”标签页支持按模型能力配置时长，并在用户提交前后验证时长合法性。

#### Scenario: 输入 Seedance 2.0 系列时长

- **WHEN** 用户选择 `doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128` 或 `doubao-seedance-2-0-mini-260615`
- **THEN** 时长输入仅接受 4 至 15 之间的整数秒
- **AND** 前端在输入值超出范围、不是整数或为空时阻止提交并显示可理解的校验提示
- **AND** 后端对绕过前端的无效请求返回验证错误

#### Scenario: 输入 Seedance 2.5 时长

- **WHEN** 用户选择 `doubao-seedance-2-5-260628`
- **THEN** 时长输入仅接受 4 至 30 之间的整数秒
- **AND** 切换模型后，若当前时长超出新模型范围，前端将时长收敛至该模型允许范围内的值
- **AND** 已提交任务的输入快照保存实际提交的模型和时长

#### Scenario: 使用自动时长

- **WHEN** 用户为任一支持的 Seedance 模型输入时长 `-1`
- **THEN** 前端将其标记为自动时长并允许提交
- **AND** 后端将 `-1` 视为合法值，不对其应用正整数时长范围校验
- **AND** 系统将 `-1` 保存到任务输入快照，并以 `duration=-1` 原样传给 Seedance

### Requirement: 全模态参考素材管理

系统 SHALL 为参考图片、参考视频和参考音频分别提供上传、资产库选择及提交前移除能力。

#### Scenario: 上传参考素材

- **WHEN** 用户在任一参考素材区域上传兼容文件
- **THEN** 系统创建并返回对应类型的工具输入资产
- **AND** 该资产立即出现在当前素材区域的已选列表中
- **AND** 当前配置预览和提交请求使用上传接口返回资产的访问 URL 与资产 ID

#### Scenario: 从资产库选择参考素材

- **WHEN** 用户打开任一参考素材的资产库选择器
- **THEN** 系统仅展示可访问且 MIME 类型兼容的公共资产
- **AND** 图片区域仅允许图片资产，视频区域仅允许视频资产，音频区域仅允许音频资产
- **AND** 用户选中的资产 ID 被加入当前配置，不复制资产文件

#### Scenario: 移除已选参考素材

- **WHEN** 用户移除当前配置中的任一已选参考图片、视频或音频
- **THEN** 系统从对应的参考资产 ID 列表中移除该引用
- **AND** 已选列表与提交请求立即同步
- **AND** 系统不得删除该资产、其对象存储文件或其他任务对该资产的引用

#### Scenario: 提交混合参考素材

- **WHEN** 用户提交包含任意组合参考图片、视频和音频的有效配置
- **THEN** 系统保存三类参考资产 ID 和实际时长到工具任务输入快照
- **AND** 系统向 Seedance 发送与三类已选资产一一对应的参考 URL
- **AND** 未选择的模态不得出现在供应商请求中

### Requirement: 全模态生视频任务重试

系统 SHALL 使用原任务输入快照中的模型、合法时长和三类参考资产 ID 重试失败的全模态生视频任务。

#### Scenario: 重试含参考素材的任务

- **WHEN** 用户重试一个失败的全模态生视频任务
- **THEN** 系统重新校验快照中的模型与时长范围
- **AND** 系统复用原始参考资产，不重新上传或复制素材
- **AND** 新任务保存与原任务一致的参考资产引用和时长
