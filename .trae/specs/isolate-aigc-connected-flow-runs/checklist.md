# 验收清单

- [ ] 无向连通范围算法覆盖链路、分支、孤立节点及 v1/v2 定义
- [ ] `from_node` 与 `retry_node` 使用起始节点所属完整连通子图
- [ ] `full` Run 覆盖整张画布并与所有活动局部 Run 冲突
- [ ] 不同连通子图可在同一 Pipeline 内同时处于 queued/running
- [ ] 同一连通子图不能同时创建两个活动 Run
- [ ] Memory 与 MySQL Repository 的冲突语义一致且检查具备原子性
- [ ] 相同幂等键仍返回原 Run，不被范围冲突破坏
- [ ] 较早 Run 后完成时不会覆盖较新 Run 的 `latest_run_status`
- [ ] 取消一个流程只取消该 Run，不影响其他流程
- [ ] 每个画布节点只展示所属流程的运行状态
- [ ] 每个流程保留自身最近终态 Run 的结果
- [ ] 选择历史 Run 仅影响其所属流程
- [ ] 一个流程运行时，其他流程的“从此节点运行”仍可使用
- [ ] 当前流程存在活动 Run 或提交中请求时禁止重复执行
- [ ] 任一流程活动或提交中时，顶部“执行全部”保持禁用
- [ ] 多个活动 Run 均独立轮询，并在各自进入终态后停止轮询
- [ ] Run 详情加载失败只影响对应流程，不清空其他流程状态
- [ ] 后端完整测试通过
- [ ] 前端完整 Vitest、TypeScript、ESLint 和 production build 通过
- [ ] Playwright 在 1440x1000、1024x768、390x844 视口通过
- [ ] Playwright 无页面异常、控制台错误、横向溢出或控件重叠
