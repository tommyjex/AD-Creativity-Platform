# 验收清单

- [x] `TEXT_TO_IMAGE` 每个实际生成 Attempt 调用命名模型一次
- [x] `IMAGE_TO_IMAGE` 每个实际生成 Attempt 调用命名模型一次
- [x] `IMAGE_EDIT` 每个实际生成 Attempt 调用命名模型一次
- [x] `VIDEO_GENERATION` 每个实际生成 Attempt 调用命名模型一次
- [x] 图层拆分、图层合成、视频处理、LLM 和输出节点不调用命名模型
- [x] 命名模型固定为 `doubao-seed-2-0-mini-260428`
- [x] 命名模型只返回包含 `name` 的结构化 JSON
- [x] 合法名称 trim 后为 1–10 个 Unicode code point
- [x] 超长、多行、控制字符、路径分隔符、扩展名和非结构化响应被拒绝
- [x] 命名输入使用 Run 与 TaskAttempt 的冻结有效提示词
- [x] 文生图命名不附加参考素材
- [x] 图生图和图片编辑按实际执行顺序附加全部参考图片
- [x] 生视频按首帧、尾帧、参考图片、参考视频的稳定顺序附加素材
- [x] 命名输入不包含参考音频或尚未生成的产物
- [x] 每个输入视频在命名请求中固定使用 `fps=0.3`
- [x] 签名 URL、密钥和原始 Provider 响应不写入数据库或普通日志
- [x] 主生成与命名在视觉参考解析完成后并行启动
- [x] 命名调用具有独立 30 秒超时
- [x] Provider 轮询、资产转存和前端轮询不会重复调用命名模型
- [x] 自动重试的新 Attempt 可重新调用一次命名模型
- [x] 缓存命中和 `REUSED` 节点不调用命名模型
- [x] 主生成失败、超时或取消时不更新节点名称
- [x] 命名失败、超时或响应非法时主生成仍可成功
- [x] 命名失败时节点名称保持不变，产物使用完成时的 fallback 节点名称
- [x] 有效 AI 名称在主生成成功后始终覆盖节点 `custom_name`
- [x] 运行期间用户手动改名也会被成功 AI 名称覆盖
- [x] 节点名称局部更新保留其他节点、连线、配置和并发用户编辑
- [x] 同一 Pipeline 多个生成节点并发完成不会丢失任一名称
- [x] 节点名称更新递增 Pipeline revision
- [x] 前端接收最新 revision，且后续自动保存不会把旧名称写回
- [x] 名称更新不改变 Run definition snapshot、输入 hash、缓存键或 Provider 参数
- [x] 新资产写入 `name_scheme="aigc_generated_node_v2"`
- [x] 新资产记录 `generated_name`、`name_source`、`naming_model` 和 `naming_status`
- [x] AI 名称有效时节点名、资产名和成功状态一致发布
- [x] 内部持久化失败不会留下可见半成品资产或名称分叉
- [x] 单产物资产与下载文件名为 `{节点名称}.{扩展名}`
- [x] 多产物第一个不追加序号，第二个起追加 `-2`、`-3`
- [x] 文件名保留合法 Unicode、清理非法字符并保留正确 MIME 扩展名
- [x] 文件名不超过现有 180-byte 上限
- [x] 节点后续改名后，可追溯资产下载使用当前节点名称
- [x] 显式 `user_defined_v1` 资产重命名继续具有最高优先级
- [x] Pipeline 或节点删除后，下载回退到资产冻结的生成名称
- [x] 历史 `aigc_canvas_node_v1` 资产无需回填且仍可正常下载
- [x] 对象存储 key、资产 ID、引用关系和历史 Run 保持不变
- [x] 节点卡片、模态详情、结果面板和资产库下载名称一致
- [x] 前端建议文件名与后端 `Content-Disposition` 一致
- [x] 不可用或不安全资产继续禁用下载
- [x] Mock 验收不调用真实图片、视频或命名计费接口
- [x] 后端定向测试和完整 pytest 通过
- [x] 前端 Vitest、TypeScript、ESLint 和 production build 通过
- [x] Playwright 在 `1440x1000`、`1024x768`、`390x844` 通过
- [x] 浏览器无新增控制台错误、重叠、溢出或不可达操作
