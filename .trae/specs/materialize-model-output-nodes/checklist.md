# 验收清单

- [x] 图片模型终端主输出成功后自动创建一个 `image` 统一模态节点
- [x] 视频模型终端主输出成功后自动创建一个 `video` 统一模态节点
- [x] 自动节点与来源模型建立类型、Handle 和方向正确的标准连线
- [x] 自动节点持久化到最新 Pipeline definition，刷新页面后仍存在
- [x] 自动节点记录来源模型 ID、主输出 Handle 和来源 Run ID
- [x] 同一来源模型与输出 Handle 最多存在一个受管自动节点
- [x] 自动节点不创建 Task Attempt、不复制媒体资产、不新增虚假任务资产关系
- [x] 缓存复用结果可触发与真实任务成功相同的幂等物化
- [x] 只有注册表类别为 `model` 的主图片/视频输出进入首期自动物化范围
- [x] LLM、字幕、音频、图层集、编辑图层和 `control` 节点不自动创建内容节点
- [x] 模型主输出尚无对应自动节点但已有其他出边时不重复创建节点或改变现有 DAG
- [x] 失败、取消、超时和 unavailable 主结果不创建或更新自动节点
- [x] 图片多产物只创建一个图片节点并展示主图片 ordinal `0`
- [x] 生视频同时返回尾帧时只创建视频节点，不额外创建尾帧图片节点
- [x] 首次自动节点位于来源模型右侧且不与已有节点碰撞
- [x] 默认位置占用时使用确定性最近垂直槽位，不移动用户节点
- [x] 重跑复用同一节点 ID 和连线，更新来源 Run 与备用资产
- [x] 重跑保留用户移动、尺寸、自定义名称和自动节点额外下游连线
- [x] 删除自动连线后节点转为普通本地节点并保留当前媒体
- [x] 解除自动关系后旧节点不再被系统更新、删除或接管
- [x] 删除自动节点后，后续满足条件的成功运行可重新创建节点
- [x] 自动节点的备用资产进入 `pipeline_assets` 保护
- [x] 当前首次物化 Run 无需修改 snapshot 或追加 RunNode即可立即展示结果
- [x] 当前 Run 即时投影仅在来源模型、输出 Handle 和来源 Run 全部匹配时生效
- [x] 后续 Run snapshot 包含自动节点时使用权威模态 RunNode 普通投影
- [x] 切换不匹配的历史 Run 时不显示其他 Run 结果
- [x] 模型失败的新 Run 不显示上次成功内容冒充本次结果
- [x] Run definition snapshot 和既有 RunNode 集合保持不可变
- [x] 后端在 Pipeline 行锁与单事务内提交自动节点、连线和一次 revision 递增
- [x] 来源模型运行期间被删除、改型或改变输出时安全跳过物化
- [x] 物化失败不改变模型任务 `succeeded/reused` 状态
- [x] 物化失败不残留半个节点、孤立连线或部分 revision
- [x] 物化失败事件写入 TLS 且不包含签名 URL、Provider 正文、凭据或堆栈
- [x] 前端 clean 状态可刷新并应用服务端自动节点 revision
- [x] 前端 dirty 状态安全合并自动节点，同时保留不冲突的本地编辑
- [x] revision 合并保持 viewport、当前选择、结果 Tab 和自动保存连续性
- [x] 自动节点图片使用固定媒体区和 `object-contain`，不裁切或拉伸
- [x] 自动节点视频使用共享播放器，支持播放、放大、原生全屏和下载
- [x] 图片支持原图查看和受控下载，文件命名沿用现有规则
- [x] 普通手工模态节点、模型节点自身结果页及既有输出展示无回归
- [x] 历史 schema v2 Pipeline、历史 Run 和 v1 只读迁移行为保持兼容
- [x] 前后端 schema、注册表、迁移和来源字段校验保持同构
- [x] Memory 与 MySQL 仓储测试覆盖创建、复用、解除、并发和回滚
- [x] Executor 测试覆盖真实成功、缓存复用、多产物、尾帧、已有下游与降级
- [x] 前端 Store、revision 合并、结果投影、节点与编辑器测试通过
- [x] 后端相关回归、Ruff 致命检查和 compileall 通过
- [x] 前端相关 Vitest、TypeScript、ESLint 和 production build 通过
- [x] Mock 图片与视频全链路验收不调用真实计费 Provider 或生产 TOS
- [x] Playwright 在 `1440x900`、`834x1112`、`390x844` 通过，无重叠或水平溢出
- [x] `git diff --check` 通过，且未覆盖工作树中的既有无关修改
