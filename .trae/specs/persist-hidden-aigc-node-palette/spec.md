# 持久化隐藏 AIGC 画布节点侧边栏 Spec

## Why

桌面 AIGC 画布当前固定展示 `184px` 节点库，即使用户主要在编辑、连线或检查结果时仍持续占用横向空间。节点库应默认隐藏，并允许用户按需展开；隐藏偏好需要在刷新或再次进入画布后保持。

## What Changes

- 桌面端节点库由固定常驻改为可显示/隐藏，浏览器首次使用时默认隐藏。
- 用户主动显示或隐藏桌面节点库后，将偏好保存到浏览器 `localStorage`，刷新及再次进入任意 Pipeline 或模板画布时恢复。
- 节点库隐藏时，在画布左上角提供紧凑的“打开节点库”图标按钮；节点库显示时，在节点库标题栏提供“隐藏节点库”图标按钮。
- 桌面节点库显示后继续使用现有 `184px` 停靠布局、分类、滚动和节点添加行为。
- 小于 `1024px` 的节点库继续使用现有 `240px` 临时覆盖面板及面板互斥规则，不读取桌面显示偏好而自动弹出。
- 节点库可见性仅属于本地 UI 偏好，不写入 Pipeline、模板 definition 或自动保存数据。
- 不新增后端 API、数据库字段或业务 DTO。

## Impact

- Affected specs:
  - AIGC 画布专业工作台布局
  - 响应式节点面板行为
  - 编辑器本地 UI 状态
- Affected code:
  - `frontend/components/workspace/aigc/aigc-editor.tsx`
  - `frontend/tests/aigc-editor.test.tsx`
  - `frontend/scripts/verify-aigc-workbench-layout.mjs`
  - `frontend/tests/setup.ts`（仅当测试需要统一清理 localStorage）

## Design Decision

- 使用全浏览器级偏好键 `aigc.node-palette.visible.v1`，不按 Pipeline 或模板分别存储；节点库可见性是用户工作区偏好，不是画布业务数据。
- 存储值仅接受 `"true"` 或 `"false"`；键不存在、值非法或访问 `localStorage` 失败时均回退为隐藏。
- 持久化只控制桌面停靠节点库。窄屏节点库仍是临时覆盖面板，进入窄屏画布时默认关闭，添加节点后自动关闭。
- 从桌面切换到窄屏时关闭桌面停靠展示，不自动打开窄屏浮层；返回桌面后恢复已保存的桌面偏好。
- 不增加拖拽宽度、自动悬停展开、快捷键或服务端同步，保持本次范围最小。

## ADDED Requirements

### Requirement: 桌面节点库默认隐藏

系统 SHALL 在宽度不小于 `1024px` 的 AIGC Pipeline 和模板编辑器中默认隐藏节点库，并将中央画布扩展至释放后的区域。

#### Scenario: 浏览器首次进入画布

- **WHEN** 用户浏览器尚未保存节点库偏好
- **AND** 用户在桌面视口进入 Pipeline 或模板画布
- **THEN** `184px` 节点库不渲染
- **AND** 画布左上角显示“打开节点库”按钮
- **AND** 右侧详情栏继续遵循现有按需显示规则

#### Scenario: 偏好不可读取

- **WHEN** `localStorage` 不可用、读取失败或保存值不是 `"true"` / `"false"`
- **THEN** 编辑器安全回退为隐藏节点库
- **AND** 画布编辑、保存和运行能力仍可使用

### Requirement: 桌面节点库显隐控制

系统 SHALL 为桌面节点库提供明确、可访问且不改变业务数据的显示和隐藏控制。

#### Scenario: 显示节点库

- **WHEN** 桌面节点库处于隐藏状态
- **AND** 用户点击“打开节点库”
- **THEN** 左侧显示宽度为 `184px` 的停靠节点库
- **AND** 节点库保留现有分组、模态图标、完整节点名称和独立滚动
- **AND** 中央画布使用剩余可用宽度
- **AND** 浏览器偏好更新为 `"true"`

#### Scenario: 隐藏节点库

- **WHEN** 桌面节点库处于显示状态
- **AND** 用户点击节点库标题栏中的“隐藏节点库”
- **THEN** 节点库收起
- **AND** 画布重新占用释放的宽度
- **AND** 浏览器偏好更新为 `"false"`
- **AND** 当前节点选择、详情标签、Run 选择和画布视口保持不变

#### Scenario: 连续添加节点

- **WHEN** 桌面节点库处于显示状态
- **AND** 用户从节点库添加节点
- **THEN** 节点按既有默认位置和配置添加
- **AND** 节点库保持显示，便于继续添加

### Requirement: 节点库偏好持久化

系统 SHALL 在当前浏览器中恢复最近一次用户主动设置的桌面节点库可见性。

#### Scenario: 刷新后恢复隐藏

- **WHEN** 用户隐藏桌面节点库后刷新当前画布
- **THEN** 节点库保持隐藏
- **AND** “打开节点库”按钮可见

#### Scenario: 刷新后恢复显示

- **WHEN** 用户显示桌面节点库后刷新当前画布
- **THEN** 节点库恢复显示
- **AND** 节点库中的“隐藏节点库”按钮可见

#### Scenario: 跨画布恢复

- **WHEN** 用户在一个 Pipeline 或模板画布设置节点库可见性
- **AND** 随后进入另一个 Pipeline 或模板画布
- **THEN** 新画布使用同一浏览器偏好

### Requirement: 响应式显隐隔离

系统 SHALL 保持窄屏节点面板的临时覆盖语义，不让桌面持久化偏好导致窄屏自动遮挡画布。

#### Scenario: 进入窄屏画布

- **WHEN** 视口宽度小于 `1024px`
- **THEN** 节点面板默认关闭
- **AND** 画布左上角显示现有“打开节点面板”入口
- **AND** 用户点击后显示 `240px` 左侧覆盖面板
- **AND** 已打开的详情面板关闭

#### Scenario: 窄屏添加节点

- **WHEN** 用户从窄屏节点面板添加节点
- **THEN** 节点按既有规则添加
- **AND** 节点面板自动关闭
- **AND** 不修改桌面节点库持久化偏好

#### Scenario: 跨越桌面断点

- **WHEN** 用户从桌面切换到小于 `1024px` 的窄屏
- **THEN** 不自动打开节点覆盖面板
- **WHEN** 用户再次切换到桌面
- **THEN** 桌面节点库按照已保存偏好显示或隐藏
- **AND** 详情栏及其当前标签继续遵循现有断点转换规则

### Requirement: 可访问控制与稳定布局

系统 SHALL 使用现有 Lucide 面板图标、可访问名称和工具提示表达节点库显隐操作。

#### Scenario: 键盘与辅助技术使用

- **WHEN** 用户通过键盘或辅助技术操作节点库
- **THEN** “打开节点库”和“隐藏节点库”均为可聚焦按钮
- **AND** 按钮提供准确的 `aria-label` 与 `title`
- **AND** 按钮通过 `aria-controls` 关联节点库，并以 `aria-expanded` 准确表达显示状态

#### Scenario: 布局无重叠

- **WHEN** 用户在 `1440x900`、`1024x768`、`768x1024` 或 `390x844` 视口切换节点库
- **THEN** 顶部命令、节点库、画布、详情栏和底部工具坞不发生不可用重叠
- **AND** 文本和图标不溢出各自容器

### Requirement: 业务状态隔离

系统 SHALL 将节点库偏好与 Pipeline、模板和运行数据隔离。

#### Scenario: 切换节点库

- **WHEN** 用户显示或隐藏节点库
- **THEN** 不调用 Pipeline 或模板更新 API
- **AND** 不触发 `800ms` 自动保存
- **AND** 不修改节点、边、视口、revision、选择状态或 Run 状态

#### Scenario: 既有命令与节点能力

- **WHEN** 用户在任意节点库状态下执行保存、运行、撤销、重做、节点添加、拖拽、连线或删除
- **THEN** 行为与变更前一致

## MODIFIED Requirements

### Requirement: 桌面专业工作台骨架

系统 SHALL 在宽度不小于 `1024px` 的编辑器中使用顶部命令栏、可选的左侧 `184px` 节点库、中央画布、按需右侧详情栏和底部画布工具坞。节点库浏览器首次默认隐藏，并按照本地偏好恢复。

### Requirement: 响应式面板行为

系统 SHALL 将桌面节点库作为持久化停靠偏好，将窄屏节点库作为临时互斥覆盖面板。跨越 `1024px` 断点不得自动打开窄屏节点面板，也不得丢失桌面偏好。

## REMOVED Requirements

### Requirement: 桌面节点库固定常驻

**Reason**: 固定占用 `184px` 会持续压缩画布，且用户在编辑与检查阶段并不总需要节点库。

**Migration**: 节点库内容、宽度和添加能力保持不变，改由画布入口按需显示；浏览器首次使用默认隐藏，之后恢复本地偏好。
